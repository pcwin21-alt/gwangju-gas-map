## 2026-11-02 공통 팔레트 반영

최신 웹의 검색·지역·필터·메뉴·목록·상세·도움말·순위·업데이트 화면을 공유한다. `assets/theme.css`의 Sand / Indigo / Jade / Sage 토큰이 두 빌드의 공통 원천이다. 플랫폼은 기존 라이트 모드를 유지하고 `brand.primaryColor`도 Jade 12 `#1D3B31`로 맞췄다. 본문 Sand 1 `#FDFDFC`, 정보 Indigo 12 `#1F2D5C`, 주요 행동 Jade 12, 선택 Sage 3을 사용한다.

`dist/test-build-manifest.json`에 실제 복사된 공통 CSS와 원본 HTML의 SHA-256을 남긴다. 기존 정보 조회용 제외 항목과 5개 데이터 보존 검사는 유지한다. 생성된 `.ait`는 새 테스트 후보이며 콘솔 업로드·실기기 확인·심사 제출을 대신하지 않는다.

플랫폼 내비게이션을 위해 웹 헤더를 숨기되 ‘더보기’는 검색 도구 줄에 유지한다. 정보 조회용 빌드에서 제공하지 않는 ‘가는 길’ 진입 버튼도 숨긴다.

## 2026-11-03 최종 점검 보완

지도가 실패해도 내부 상세 팝업에서 주소·가맹 근거와 확인일·확보된 가격을 확인할 수 있다. 검색어 지우기와 전체 초기화, 지도 없는 화면의 Escape 처리를 보완했다. 공개 웹 소스에는 적용하지 않는 플랫폼 전용 변환이다.

재빌드할 때 참조되지 않는 이전 JS를 제외하고 정적 자산에 입력 해시 기반 버전을 붙인다. `verify_bundle.py`는 실제 `.ait` 안의 파일, 원본 입력 해시, 데이터 보존, JS 문법과 제외 항목을 확인한다. 이 검사도 콘솔 업로드나 실제 토스 앱 검증을 수행하지 않으며 제출 가능을 자동 판정하지 않는다. 최신 제출 조건과 남은 확인은 `docs/apps-in-toss/REVIEW_ROUTE_20261103.md`를 따른다.
