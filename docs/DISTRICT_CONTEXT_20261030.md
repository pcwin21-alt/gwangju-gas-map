# 광주 자치구 경계 안내

요청: 구 경계 근처에서 어느 구인지 식별할 수 있게 표시한다.

- 기존 단일 카카오 지도와 광주 5개 구 경계 좌표를 그대로 사용한다. 경계 자료를 새로 수집하거나 정확도를 재검증한 변경은 아니다.
- 지도 중심에서 경계까지 화면상 110px 이내이고 카카오 지도 확대 수준이 8 이하일 때 안내한다. 실제 GPS 위치와 지도 중심을 혼동하지 않도록 `지도 중심 · 서구`와 인접 구를 표시한다.
- 가까운 구 최대 3개의 이름을 화면에 보이는 각 구 영역 안에 놓는다. 텍스트가 들어갈 공간이 부족하면 해당 구 이름 표시는 생략한다. 이동·확대 중에는 숨겼다가 이동이 끝나면 다시 계산한다.
- 이름과 안내는 터치를 가로채지 않는다. 기존 경계 클릭 필터·주유소 필터·경로·위치 권한 동작을 유지한다. 추가 위치 조회와 외부 API 호출이 없다.
- 작은 화면에서는 하단 중앙 안내가 확대·축소 및 내 위치 버튼을 피한다. 테마의 기존 배경색과 글자색을 사용한다.

구현: `assets/district-context-core.js`의 화면 좌표 기하 계산, `assets/district-context.js`의 카카오 오버레이와 지도 이벤트 연동, `assets/district-context.css`의 표시 스타일.

검증: Node 55개, Python 100개 통과. 공유 경계 양측 이름·경계를 넘어간 중심 구 변경·경계에서 먼 곳 숨김·구 영역 외부·다중 폴리곤·구멍·좁은 영역의 이름 생략·지도 이동 및 확대/크기 변경 이벤트를 확인했다. 배포 후 실제 화면 검증은 아래에 기록한다.
