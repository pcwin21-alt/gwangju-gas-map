# 카드사 위치 조회를 통한 추가 발견 — 2026-10-26

## 작업 계약과 경로

전남을 먼저 조사하고, 현재 가맹 근거와 정확한 영업장 식별을 함께 확보한 지점을 지도에 추가한다. 기존 명부의 수를 늘리기 위해 미확인을 확정으로 바꾸지 않는다. 입력은 공식 상권자료, 과거/연간 온누리 명부, KB국민카드의 로그인 없는 공개 온누리 사용처 조회다. 수락 증거는 같은 업체의 명칭·차량 연료 업종·주소권역·좌표 일치와 카드사의 온누리 표시다. 결제 실증과 다른 카드사 지원 여부는 별도다.

하네스: root/Brain always, Project Execution·Source·Global Eval active. UI의 출처 표시에는 KRDS 가독성 기준 active. 기존 구조·CSS를 유지하고 출처/미확인 정보는 색이 아닌 글자로 구분했다. 새 제품 기획·출판 문체·다른 플랫폼 스킬은 범위 밖으로 excluded. hwp·컴퓨터 조작 스킬은 경로 검토용 reference로 읽었으며 HWP 변환이나 Windows 조작은 실행하지 않았다. index의 workspace_root는 옛 폴더를 가리키는 drift가 있어 실제 canonical root를 사용했다. 정본 하네스·기억 파일은 수정하지 않았다.

## 실제 해결한 조회 문제

KB 공개 페이지의 상호 검색은 위치 좌표를 함께 사용한다. 페이지 원문의 초기 좌표는 0,0이다. 동일 상호 `현대주유소`를 0,0에서 조회하면 0건, 실제 순천 영업장 좌표에서 조회하면 1건이다. 이 대조 실험을 `kb_coordinate_control_20261026.json`에 보관했다. 이전 상호 검색 0건을 미가맹 증거로 쓰지 않았던 판단은 유지하되, 검색 불능 원인을 위치 좌표로 좁혔다.

공개 폼의 요청 항목을 그대로 사용했다: `useCase=1`(온누리), 실제 공개 사업장 좌표, 상호, 10건 단위 페이지. 인증·사용자 위치·기존 브라우저 세션을 가져오지 않는다. 페이지당 수·가맹점 ID 중복·온누리 표시를 검증하고, 오류 시 재시도하지 않고 중단한다. 간격은 최소 1.5초다. 온누리 운영사 서버에 추가 격자 요청은 보내지 않는다.

## 확인한 지점

**현대주유소, 순천시 중앙로 172**

- KB 조회 업종: 주유소. 온누리 표시 `onNuliGb=1`.
- KB 가맹점 식별자: `000000004645863`.
- KB 공개 전화: 061-752-3327. 주소권역: 전남 순천시 매곡동.
- KB 좌표: 34.961063692, 127.4847504375.
- 공식 상권자료 상호·도로명주소·매곡동 지번 일치. 두 좌표 차이 10.1m.
- 2021 지류 명부 주소 중앙로 172·매곡동 55-1과도 일치. 2026-07-31 연간 명부의 웃장 소속 현대주유소 후보와 연결.
- 지도에서는 KB국민카드 조회 기준 디지털 카드 사용처로 구분한다. 지류·QR은 null(미확인)이며, 다른 카드사에 지원 여부를 전파하지 않는다.

무안 동부·해제주유소는 정확한 업체 위치에서 상호로 조회해도 반환되지 않았다. 해제면 주변 조회 자체는 일반 가맹점 4건이 반환돼 동작을 확인했다. 카드사의 반영 지연·지원 범위가 있어 이 결과만으로 미가맹을 단정하지 않는다.

## 데이터와 운영 경계

카드사 상세주소가 읍면동까지만 제공되므로 좌표와 이름만 보고 지점 추가를 허용하지 않는다. 공식 상권자료의 동일 상호·동일 주소권역·차량 연료 코드·100m 이내 좌표가 필요하고, 검토된 근거 파일만 게시 과정에 사용한다. 이미 지도에 있는 동일 주소에는 다른 이름의 새 마커를 더하지 않는다.

KB 근거는 운영사 검색 스냅샷과 분리한다. 지도 ID도 `onnuri:kb:...`로 구분한다. 운영사 마지막 성공일 2026-10-25와 가격 파일은 유지한다. 카드사 원천 데이터 기준일은 알 수 없어 조회일과 혼동하지 않는다. 30일이 지나면 오래된 기록으로 표시하고 경유 추천에서 제외한다. 운영사 전체 갱신이 실패해도 카드사 근거를 유지하되 그 유효기간을 계산한다.

초기 반영 검증: 기존 206개 데이터 행 그대로 보존, 현대 1행 추가. 좌표 있는 지도 지점 203 → 204, 전남 22 → 23, 대기 17 → 16. Python 84개·Node 20개 테스트 통과. 로컬 브라우저에서 전남 공유 링크의 지역·결제 필터 복원, 현대 검색, 상세주소와 KB 조회/지류·QR 미확인 표시를 확인했다. 로컬에서는 지도 공급자의 도메인 제한으로 목록 대체 화면을 검수했다. 공개 지도 검수는 배포 기록에 별도로 남긴다.

## 완료된 발견 조사

전남의 945개 위치·검색어 조합을 모두 조회했다. KB 가맹점 ID 21개(장성농협의 동일 위치 ID 2개 포함)가 반환됐고, 신규 지도 지점은 현대주유소 1곳이다. 이 조사는 공식 상권자료에 실린 차량 연료 업종을 출발점으로 삼은 후보 조사이며, 검색 반경·은행 수록 범위가 불명확하므로 전남 모든 온누리 가맹점의 전수조사로 볼 수 없다.

이후 전북→경북→대구→충남→충북→경기 순으로 과거/대기 후보의 실제 위치 22곳을 조회했다. 서울 조회는 하지 않았다. 7개 신규 지점이 확인됐다.

| 지역 | 지점 | 확인 주소 |
|---|---|---|
| 경북 경주 | 양북주유소 | 문무대왕면 감은로 23 |
| 경북 문경 | 문희주유소 | 문경읍 청운로 47 |
| 경북 봉화 | 춘양주유소 | 춘양면 의양로 81 |
| 경북 안동 | 대원석유주식회사직영명륜주유소 | 퇴계로 134 |
| 경북 울진 | 기성주유소 | 기성면 기성로 633 |
| 충북 음성 | 원남주유소 | 원남면 충청대로 1139 |
| 경기 파주 | 광탄주유소 | 광탄면 혜음로 1178 |

7곳 모두 KB 좌표와 공식 상권자료 좌표 차이가 5.8~11.1m였다. 양북면은 2021-04-01 문무대왕면으로 바뀐 공식 명칭 변경을 적용했다. 명륜은 상권자료의 `명륜주유소`와 `대원석유직영명륜주유소주`가 동일 주소·지번·좌표이며, 카드사 법인 표기를 해당 ID 쌍에만 연결했다. 일반적인 부분 상호 매칭은 허용하지 않는다.

문희·원남·광탄의 옛 명부 지번/동리와 현재 상세주소가 달라, 과거 후보의 동일성까지 확정하지 않았다. 현재 KB 가맹점은 독립된 근거로 지도에 올리고 기존 연간 후보는 확인 대기로 유지했다. 양북·춘양·명륜·기성은 이전에 확인한 동일 주소 근거와 연결했다.

최종 로컬 검증: 기존 206개 행 보존, 신규 8개, 총 데이터 214개·유효 좌표 지도 211곳(기존 203), 전남 23곳, 확인 대기 12개. Python 86개·Node 20개 테스트 통과. 원천 온누리 스냅샷·가격·마지막 운영사 성공일은 보존했다. 최초 현대 1곳 배포(c6c2219)의 CI·Pages 성공과 공개 지도 전남 23곳 표시를 확인했다. 후속 7곳의 공개 검수는 최종 배포 기록에서 확인한다.

기존 순천 호남주유소·순천주유소의 운영사 좌표가 은행 좌표와 각각 약 351m·248m 차이 나는 것도 발견했다. 이 둘은 이미 지도에 있는 곳으로 신규 수에 포함하지 않았으며, 위치 교정은 별도 검토 사항으로 남겼다.
