## 포털별 실제 접근

- **구글:** 단순 HTTP 조회는 자바스크립트 안내 화면이었다. 정상 브라우저에서 같은 검색어 `전남 온누리 주유소 결제`의 실제 검색 결과를 확인하고, 가장 관련성이 높은 155곳 목록을 열어 전부 대조했다. AI 개요는 증거로 쓰지 않았다.
- **네이버:** 네이버 블로그 리서치 스킬의 검색 기능으로 1페이지를 요청했으나 HTTP 403이었다. 중단했으며 다른 IP·프록시·모바일 주소로 재시도하지 않았다. 구글에 노출된 네이버 글 제목·요약은 원문 확인 및 결제 검증과 구별했다. 네이버 전체 검색을 완료했다고 보고하지 않는다.
- **다음:** 실제 통합검색 결과가 HTTP 200으로 열렸고, 그 결과의 기사 원문을 확인했다.
- **공개 웹 검색:** 목포·여수·순천·나주·광양과 17개 군의 지역명 질의, LPG·지류·QR·실제 결제 표현을 사용했다. 이는 검색 결과 검토이며 모든 블로그·카페·가맹점의 전수 조사가 아니다. 거절된 운영사/카드사 원천의 추가 조회는 하지 않았다.

접근 결과는 `output/audits/portal_search_20261103/*_search_attempt.json`에 기록한다. 원문 제한·검색만 확인·목록 재인용·실제 가맹 증거를 구분한다.
