# 추가 발견 경로 재검토 — 2026-10-26

## 계약과 판정

질문: 기존 8곳 추가가 탐색의 끝인지, 어떤 다른 방법이 실제 누락을 찾을 수 있는지 확인한다. 기존 조사 기록·현재 지도·공개 원천을 검토하고 새로운 조회 방식은 소량 실험한다. 수락 조건은 미조사 범위와 작동 확인/미실행/접근 실패를 구분하는 것이다. 지점 수 증가 자체를 조사 성공으로 정의하지 않는다.

라우팅: canonical root AGENTS/Brain always, Research Synthesis Agent·Source·Global Eval active. 기존 프로젝트 기록 reference. UI 구현·발행·기관 연락·계정 접근·메모리 수정 excluded. harness_index의 옛 workspace_root는 drift. 실행 정본은 실제 canonical 경로를 사용했다.

## 기존 범위의 핵심 한계

- 전남 945개 위치·검색어 조합은 소상공인 상권자료에 수록된 연료 업종을 출발점으로 한 KB 상호 조건 조회다. 모든 영업장·모든 카드사·모든 결제수단을 포괄하지 않는다.
- 전남 외 지역은 과거/미확인 후보 22곳만 조회했다. 같은 방식의 전국 후보 조사는 아직 끝내지 않았다. 이 미조사 범위가 새로운 원천 탐색보다 먼저 고려할 큰 기회다.
- 현재 유효 좌표 지도 211개는 광주상생카드도 포함한다. 온누리 표시가 있는 행은 178개다. 이는 최신 전국 온누리 가맹 주유소의 총수나 결제 실증 수가 아니다.

## 새 실험: 상호 조건을 없앤 주변 가맹점 전부 조회

KB 공개 지도 폼이 쓰는 실제 좌표, useCase=1, 빈 mmcNm으로 세 지점을 조회했다. 운영사 차단 서버는 재호출하지 않았고, 인증이나 사용자 위치를 사용하지 않았다.

확장 방식: 기존 이름 조건 조회가 0건인 위치에서 무검색어 결과를 받고, 반환된 업종/상호/좌표를 공식 영업장 주소와 대조한다. 단순 인접 점포, 같은 건물의 정비소를 주유소로 연결하지 않는다. 은행 업종이 다르면 자동 지도 승격 없이 독립 식별 근거를 더 요구한다.

## 다음 세 가지 경로

1. **미조사 지역 확대**: 현재 작동이 확인된 실제 좌표 조회를 전남 이후 정해진 광역지자체 순서로 적용한다. 서울 마지막. 전국 후보 전부를 이미 조회한 것처럼 보고하지 않는다.
2. **후보 명부 자체의 누락 검사**: 상권자료의 연료 업종만 출발점으로 삼지 않고, 시군 주유소·LPG 인허가 명부와 오피넷 영업장 목록을 주소 기준으로 합친 뒤 상권자료 밖의 영업장을 추출한다. 새로 확보한 후보도 온누리 가맹 확인이 별도로 필요하다. 이번에는 목포·순천·영광군의 공식 데이터 페이지 존재와 항목을 확인했고 전체 파일 비교는 아직 하지 않았다. 목포는 검색색인과 열린 페이지의 기준일이 달라 다운로드 원본으로 확인해야 한다.
3. **신규 상점가의 구역·주소 중심 조사**: 연간 온누리 파일 이후 지정된 구역의 주유소를 추출한다. 기존에 발굴한 장성 고시는 이번에도 웹 도구에서 열리지 않아 첨부 구역도 분석이 미완료다. 지정 사실 자체를 점포 가맹으로 간주하지 않는다.

## 낮게 평가한 경로와 한계

- 다른 카드사 조회를 조사했지만, 이번 검색에서는 KB와 동등하게 쓸 수 있는 독립 공개 온누리 명부를 확보하지 못했다. BC의 옛 전자상품권 안내는 외부 시장 조회로 연결되고 신한 검색에는 다른 지원금 사용처가 섞였다. 지원금 가맹을 온누리 가맹으로 취급하지 않는다.
- 민간 온누리 사이트 다수는 같은 연간 공개파일을 재가공하므로 사이트 수가 늘어도 독립 원천이 늘었다고 볼 수 없다.
- 소진공 가맹점 플랫폼 공개 공지 URL은 직접 요청 HTTP 400, 웹 열기는 timeout이었다. 전체 상세주소 파일 제공 가능 여부는 확인하지 못했다.
- 기관에 상세주소·현재 상태·결제수단·변경일이 있는 자료 제공을 요청하는 방안은 남아 있지만 연락/제출은 하지 않았다.

지도 데이터와 공개 사이트는 이번 조사에서 변경하지 않았다. 소량 실험 완료, 전국 조사/새 가맹점 추가 완료 아님. Global Eval: 범위·원천·조회 결과·불확실성·다음 행동을 분리해 기록함.
