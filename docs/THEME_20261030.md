# 밝은/어두운 화면

- 요청: 밝은 환경과 어두운 환경에서 가시성을 개선하는 화이트/다크 모드.
- 수락: 더보기에서 기기 설정/밝게/어둡게, 선택 저장·재방문 복원, OS 변경 자동 반영, UI/지도/상세/가격/필터/입력/안내의 읽기성, 기존 가맹점 조건 유지.
- canonical harness의 기존 Project Execution/Brain/Source/Eval, codex-delivery-loop/computer-use/KRDS 후속 적용. 신규 제품 기획·데이터 조사·개인정보 수집 제외.
- theme.js를 head에서 실행해 최초 렌더 전에 색상 적용. localStorage 차단/손상 값은 기기 설정으로 복구. 문서 색상 체계와 브라우저 theme-color 동기화.
- 기본 메뉴는 늘리지 않고 더보기 안에 화면 테마 선택을 배치. 밝음은 흰 패널/짙은 글자, 어두움은 남색 패널/밝은 글자, 선과 포커스는 별도 대비.
- 어두운 지도는 이미 추가한 MapLibre/OpenFreeMap dark 스타일(공개 URL HTTP 200 확인, 47개 레이어)을 사용. 카카오 타일을 색상 반전하지 않음. 밤에는 벡터 지도 자동 준비. 밝음 복귀는 liberty 스타일. 스타일을 바꾼 뒤 가맹점 레이어를 다시 붙이며 현재 필터에서 데이터를 생성.
- 지도를 통한 위치 제보는 기존 카카오 지도로 복귀하는 기존 경로 유지. 이 작업에서 지도/가격/가맹점 데이터 변경 없음.
- 대비 테스트: 본문·보조 글자·주요 버튼의 전경/배경 4.5:1 이상. 이것은 지정 토큰에 대한 자동 검사이며 전체 페이지 접근성 인증을 의미하지 않음.
- 새 단위 검사: OS 변경, 수동 우선순위와 재방문 복원, 저장소 실패, 토큰 대비, 지도 스타일 교체 후 가맹점 유지.
- 상태: 구현 및 관련 단위 검사 통과, 브라우저 시각·연결 검수 대기.
