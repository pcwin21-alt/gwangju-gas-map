# 내 위치 지도 버튼

요청: 내 위치 검색·이동을 지도 우측 하단 버튼 하나로 제공. 기존 UI 간소화의 후속 수정.

## 레퍼런스 관찰 (2026-10-30)
- PC https://map.naver.com/p/ 실제 렌더: 우측 하단 확대/축소 위에 흰 사각형, 가는 테두리와 조준점 아이콘. 접근성 트리에서는 접속위치 조작으로 표시.
- 모바일 웹 https://m.map.naver.com/ 390×844 실제 렌더: 현재위치 버튼은 지도 좌측 상단. 우측 하단은 확대/축소. PC/모바일의 위치가 같다고 가정하지 않음. 네이티브 앱은 미검수.
- 공통 적용: 지도 조작은 지도 위에 분리, 흰 바탕과 테두리로 지도 위 대비 확보, 작은 조준점 아이콘 사용. 네이버의 지도 내 위치 버튼 자체는 누르지 않았으며 위치 권한을 요청하지 않음.
- 번역 결정: 사용자 지정 우측 하단, 48×48px 터치 영역과 24px SVG. 결과 보기는 그 위로 8px 간격 배치. 상단 내 위치 중복 제거. 지도 서비스 로고와 하단 안전영역 확보.
- 제외: 네이버의 테마/저장/거리뷰 등 보조 도구, 네이티브 앱의 지속 위치 추적. 이 버튼은 명시적인 클릭에 한 번 위치를 조회하고 중심 이동.

## 계약 및 검수
- canonical harness의 기존 라우팅과 codex-delivery-loop, computer-use, Project Execution, KRDS 기준을 후속 적용. 관련 기준은 UI_SIMPLIFICATION_20261030.md에 연결.
- 수락: 상단 버튼 제거, 지도 우측 하단 위치 버튼 하나, 결과 보기와 비중첩, 로딩 때 중복 클릭 방지·아이콘 유지, 실패 때 재시도, 한/영 접근성 이름, SDK 미로드 시 비활성화.
- 조작은 48px, 본문 변경 없음. SVG는 장식이며 aria-label/title로 기능 전달. 로딩 aria-busy 및 감소 모션 지원.
- 신규 위치 성공/실패 단위 검사는 실제 GPS를 사용하지 않는 mock. 실제 위치 권한/정확도는 브라우저·기기 조건에 의존.
- 가맹점/가격 자료 변경 없음. 기존 사용자 수정 파일 보존.
- 배포 검수: 모바일 390×844에서 버튼 48×48, 우측 여백 14px/하단 24px, 결과 보기와 8px 간격 확인. 상단 내 위치 없음, 전체 내 위치 버튼 1개 확인.
- PC 1280×900에서 펼친 주유소 목록이 기존 높이대로 버튼을 덮는 것을 발견, 목록 최대 높이에 152px의 하단 조작 공간을 확보하도록 보정.
- CI: Node 위치 상태 신규 2개 및 기존 24개, Python 기존 100개 통과. 첫 배포/검사 Actions 40967732144, 40967731671, 40967732228.
