## 대체 경로 1: 전체 공식 파일의 역방향 대조 — 실행 완료

[2026-07-31 온누리 명부](https://www.data.go.kr/data/3060079/fileData.do)의 실제 CSV 225,803행과 [2026-06-30 상가·상권정보](https://www.data.go.kr/data/15083033/fileData.do)의 16개 CSV 2,772,484행을 사용했다. 포털 화면의 전체 행 메타데이터와 다운로드 파일의 행 수는 다르므로 여기에는 해시 확인된 실제 파일 수를 썼다.

상권정보에서 차량 주유·가스충전 업종 12,551행을 추출했다. 전남 856행도 포함된다. 이는 해당 자료의 행 수이며 전체 인허가 사업체 수나 중복 제거된 실제 주유소 총수로 해석하지 않는다. 이름을 전체 온누리 명부와 역대조해 153행이 일치했다. 기존 연료 후보에 없던 35행 중 34행은 공식 취급품목이 음식·의류·수산물·잡화 등이고, 공란 1행인 `으뜸`은 전주의 작은모래내 상점가와 부안의 업체를 연결한 동명이명 문제였다. 신규 확정·지도 추가는 0이다.

[전주시 공식 지정 고시](https://www.jeonju.go.kr/deokjingu/planweb/board/view.9is?boardUid=9be517a7914528ce01930aa3ddc26cf0&contentUid=ff8080818990c349018b041a879f395a&dataUid=5d083c3883fe436396ab8ed3512e63ee&page=128&subPath=%2Fdeokjingu&tmpField14=)로 작은모래내의 지역을 확인했다. 이름이 같다는 이유로 다른 업체의 좌표를 온누리 가맹점에 붙이지 않는다. 기존 non_vehicle 자동 규칙이 잡지 못한 26행도 적합 후보를 뜻하지 않으며 별도 검토 기록에 모두 추가 불가로 기록했다.

산출물: `scripts/discover_bulk_candidates.py`, `output/bulk_reverse_candidates_20261026.json`, `output/alternatives/bulk_name_match_review_20261026.json`. 입력 파일 해시·지역별 행 수·필수 필드·전체 행 수 검증을 통과했다.

## 대체 경로 2: 주소가 있는 별도 공식 과거 명부 — 실제 연결 근거 확보

[소상공인시장진흥공단 종이상품권가맹점](https://www.data.go.kr/data/15091227/fileData.do)은 2021-09-28 기준 일회성 공개자료다. 실제 다운로드 CSV 155,519행에 시장명·점포명·취급품목·주소가 있다. 전국 최신 명부의 시도만 있는 소재지 열과 달리 상세주소를 제공한다.

검토 대기 고유 후보 18곳 중 11곳에 동명·동일 시도 과거 기록이 있었고, 그중 8곳은 시장명도 정규화 후 정확히 일치했다. 나머지 3곳은 시장명 별칭 검토가 필요하다. 동명이인 후보 복수, 불완전한 번지, 시장명 변경 등은 결과에 그대로 남겼다.

전남의 현대주유소는 과거 명부에 `순천웃장 / 현대주유소 / 주유소 / 전남 순천시 중앙로 172(매곡동 55-1)`로 나온다. 2026 명부의 `웃장 / 현대주유소`와 기존 상권자료의 주소를 연결할 근거가 추가됐다. 이는 현재 디지털 가맹이나 현장 결제 확정이 아니므로 지도에 새 확정 지점으로 올리지 않았다.

산출물: `scripts/link_historical_merchants.py`, `output/alternatives/paper_merchants_source.json`, `output/alternatives/pending_historical_addresses_20261026.json`. 원본 CSV는 같은 로컬 폴더에 보존했다. 해시·행 수 확인, 11개 연결·8개 정확한 시장명 일치, 전남 우선 정렬을 검증했다.

## 대체 경로 3: 카드사 별도 공식 조회 — 모바일 및 PC 실조회

[KB국민카드 정부지원사업 사용처 찾기](https://mkbpay.kbcard.com/BON/DVIEW/MBAM0005)에 온누리 필터, 지역·가맹점명 검색, 300m/500m/1km 반경이 있다. 카드사 자체 등록 주소를 사용하며 사업 정보가 실시간 반영되지 않는다는 안내도 있다.

브라우저에서 온누리·1km·전남 순천시 조건을 설정했다. 매곡동을 선택하려 했으나 실제 적용된 조건은 가곡동으로 남았고, 그 조건의 결과는 0건이었다. 이를 현대주유소의 비가맹 근거로 쓰지 않는다. 이 경로의 개별 대상 검증은 아직 성공하지 않았으며 전국 일괄 수집 경로로 검증되지 않았다. 사용자 위치 권한이나 로그인을 요청하지 않았다.

## 보조 자료와 운영 방향

- 지자체·대학의 첨부 명부도 별도 주소 근거가 된다. [목포대 2024-09-30 공지](https://marine.mokpo.ac.kr/bbs/trade/255/267551/artclView.do)에 2024-09-26 후문 상권 온누리 명부 XLSX가 있다. 지역 범위와 시점이 좁아 전국 최신 명부의 대체재로 취급하지 않았다.
- 공공데이터포털의 오픈 API 탭은 공개 파일을 JSON/XML로 변환한 방식이다. 그 API만 신청하면 누락된 상세주소·실시간 가맹상태가 생기는 것은 아니다.
- 장기 자동화에는 소진공에 공개 가맹점 식별자·도로명주소·좌표·결제수단·변경일을 포함한 최신 데이터 제공 또는 허용된 정기 조회 경로를 요청하는 방안이 적절하다. 요청 가능성이 제공 승인을 뜻하지 않으며, 이번에 기관 연락·민원 제출은 하지 않았다.
- 추천 순서: 최신 명부의 가맹 이력 → 과거 공식 주소 연결 → 최신 상권/인허가 자료로 같은 업체인지 확인 → 카드사 등 별도 현재 자료 대조. 지도에는 근거 기준일과 결제 유형을 분리해 반영한다. 시장 대표좌표를 주유소 좌표로 쓰지 않는다.
