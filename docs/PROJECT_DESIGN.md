# 가는 길 주유소 경유 기능과 가맹점 확인 기록

## 계약
- 이용자: 광주권에서 온누리/상생카드 주유소에 들러 목적지로 이동하는 운전자.
- 첫 흐름: 출발지(직접 검색 또는 위치 허용) → 최종 목적지 선택 → 결제수단 → 추가 이동시간 비교 → 주유소 경유 링크.
- 수락 증거: 실제 장소 검색·OSRM 응답·추천 5곳 렌더·출발/경유/목적지 각각의 좌표 전달, 모바일 가로 넘침 없음.
- 범위 밖: 실행 중인 내비 경로 읽기, 직접 음성 길안내, 실시간 교통·주유 대기·입구 방향 보장.

## 데이터
- 상생카드: 광주시 공식 조회 API에서 `주유`와 `가스` 업종 검색, 모든 페이지·예상 건수·고유 sn 검증. 단 하나의 페이지라도 실패하면 기존 데이터 유지 및 작업 실패.
- 온누리: 공공데이터포털 3060079의 공식 CSV(표기 기준일 2026-07-31)를 대체 수집원으로 사용. 상세주소/좌표 없이 `전남광주` 통합 지역명만 제공되므로 과거 원본과 상호명+상점가가 모두 일치하는 100곳만 대조 갱신. 3곳은 2026-03-03 과거 기록(`stale`) 유지. 누락을 폐업/가맹 취소로 추정하지 않음.
- 공식 CSV는 지류형/디지털형만 구분. 디지털 Y를 카드/QR 각각 Y로 추정하지 않고 별도 digital 필드로 필터링. 주소와 좌표는 과거 위치 기록을 유지하며 확인일과 자료 기준일을 분리. 신규/동명/상점가 불일치는 검토 목록에 남기고 지도에 임의 추가하지 않음.
- 출처 보존: 정규화한 지역 연료업종 후보 164행과 다운로드 URL, 파일 SHA256, 실제 전체 행수(225803), 수신일을 `onnuri_official_snapshot.json`에 저장. 포털 메타데이터 행수(125589)와 실제 CSV 행수가 달라 실제 파일의 컬럼/지역/결제값/최소 행수를 검사. 기준일은 포털 표기일이며 실시간 가맹 확인일이 아님.
- 새 가맹점 수집기와 지도 동기화 코드를 GitHub에 포함. 기존 `.claude` 비추적 스크립트 의존 해소.
- 도로명+건물번호 일치 및 좌표 40m 이내이며 후보 한 곳인 경우에만 소스 병합. 150m 근접만으로 결제 태그 전파하지 않음.
- 상세 주소 없는 과거 항목은 검토 장부에 보관. 좌표/자동차 주유 업종 확인이 안 된 장소는 내비 추천에서 제외.
- 갱신 실패와 확인일을 보존. 상생카드 확인과 온누리 과거 확인을 별도로 표시.

## 경로
- 후보 최대 24곳을 직선 추가거리로 미리 좁힌 후 도로 시간 행렬로 비교. 광주 전체 최적이라는 주장은 하지 않음.
- 추가시간: 출발→주유소 시간 + 주유소→목적지 시간 − 출발→목적지 시간.
- 도로에 150m 이상 멀리 스냅되는 후보와 도달 불가(null)는 추천 제외.
- OSRM 공개 데모를 소규모 비상업 시험에만 사용. 자동 조회 없음, 요청 간격 1.1초, 세션 캐시, 조회당 행렬 1회, 20초 제한. 상시/상업 운영 시 전용 경로 서버나 공식 길찾기 API로 교체 필요.
- 좌표가 서비스에 전달된다는 안내 후 이용자가 비교 버튼을 누르면 조회. 계정/이동 이력/브라우저 권한 자동 수집 없음.
- 네이버 모바일 공식 URL scheme에 최종 목적지와 v1 경유지 별도 전달. Android 미설치 fallback은 세 지점이 포함된 카카오맵 경로. PC에서는 카카오맵 경유 링크 제공.
- 실제 iOS/Android 네이버 내비 실행은 사용자 휴대폰 확인 필요. 브라우저 검증은 URL 필드와 도로 계산까지만 검증함.

## 운영과 검증
- 상생카드 매일 KST 06:30 확인. 온누리도 공식 파일 페이지를 확인하고, 파일/기준일 변경 또는 7일 경과 시 CSV 재수신. 다운로드/검사 실패 시 마지막 검증된 파일과 날짜를 보존하며 화면에 실패 표시.
- 유가 갱신·가맹점 갱신·배포를 같은 concurrency group으로 직렬화, public allowlist `_site`만 배포.
- JS/CSS 내용 SHA256을 배포 URL 버전에 반영. 공개 확인 중 새 HTML과 캐시된 구형 날짜 안내 스크립트가 섞이는 현상을 확인하여 보완.
- 자동 검사: 페이지 누락/반복 거부, 인접 장소 오병합 방지, 상호 변경 병합, 지류 전용 보존, 주공주유소 상생 태그, 경유 좌표·이름 URL 인코딩, null 시간/멀리 떨어진 도로 거부.
- 브라우저 실제 확인: 광주청사→광주역 검색 및 5곳 추가시간 결과, 모바일 390px 레이아웃.
- 2026-10-10 수락 증거: Python 14개/Node 8개 검사 통과, 기존 100곳 온누리 공식 대조, 매칭 미완료 3곳 과거 표시, 실제 상세창의 지류·디지털/자료 기준일 확인.
- 조회 현황 배너는 상단에서 제거하고 `업데이트 내역` 버튼의 팝업으로 이동. 10/9~10/10 기능 변경 내역과 현재 자동 갱신 상태를 함께 표시. native dialog로 배경 조작 차단·Esc 닫기·버튼 포커스 복귀를 적용했고, 모바일 390px 가로 넘침 없음과 닫기 버튼을 브라우저에서 확인.
- 경유 기능 입구를 초록색 `경유 주유소 찾기` CTA로 강조. native details의 키보드 조작을 유지하고 열기/접기 상태와 목적지·추가 이동시간 비교 안내를 표시.
- 모바일 지도: 구는 선택형 필터로 축소하고 기본은 전체 지역으로 유지. 지역·결제수단·검색 결과를 지도 범위에 자동 맞춤하고 `결과 보기`로 다시 맞춤. 화면 폭/회전 변화는 결과 범위를 재계산하며, 높이 변화는 현재 중심을 보존하고 Kakao SDK relayout 실행.
- 모바일 수락 증거(2026-10-10): 390×844 브라우저에서 전체 150곳 및 5개 구(47/22/7/55/19곳)의 마커가 지도 안에 들어옴. 단일 검색 확대, 경유창 열기/접기, 844×390 회전 및 가로 넘침 없음 확인. 실기기 검증은 별도. Python 14개·Node 11개 검사 통과.
- 모바일 비주얼 개편(2026-10-10): 흰색/짙은 청록의 공통 색상과 44px 이상 주요 터치 영역 적용. 검색과 결제 필터를 우선 배치하고, 위치·가격 순위·경유 검색은 바로 접근. 제보·내보내기·업데이트·후원·반응은 native dialog 더보기로 이동. 기존 버튼 ID와 기능을 보존하고 보조 시트를 먼저 닫은 뒤 대상 기능을 실행. 업데이트 닫기/Esc 후 더보기로 초점 복귀. 결과 보기만 지도 하단에 배치하고 마커 맞춤 여백 조정.
- 비주얼 수락 증거: 320/390px 세로, 844px 가로, 1280px 데스크톱 브라우저에서 가로 넘침 없음. 390×844 설정의 실제 CSS 화면에서 지도 높이 약 371→501px. 가격 순위·도움말·더보기→업데이트·Esc·지역 변경·경유 폼 확인. 좁은 화면 경유 검색 버튼과 결제 선택창 눌림 보정. Python 14개/Node 11개 통과; 실제 휴대폰 확인은 별도.
- 미해결: 온누리 실시간 상태·신규 후보 상세주소 확인, 상생카드 좌표 없는 일부 기록, 내비 앱 실기기 확인, 실시간 교통 기반 경로 서버.
