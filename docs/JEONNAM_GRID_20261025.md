## 초기 방식과 이번 변경

초기 로컬 `.claude/skills/data-fetcher/scripts/fetch_onnuri_place.py`는 구형 `/api/v1/place/search`를 사용했다. 위도 0.013°, 경도 0.016° 간격으로 광주 bounding box를 나누고 `주유소/주유/석유` 3개 검색어를 조회했다. 문서상 반경은 1km이며 과거 114건을 확보했다. 당시 코드는 첫 응답만 수집하고 오류를 빈 목록처럼 처리하므로 그대로 재실행하지 않는다.

현행 공식 공개 클라이언트 `useForm-Dr8J7NKv.js`와 `usePlace-Cp_hVIDZ.js`에서 `/api/v3/onrgt/place/search`, 주변 검색 `keyword=''`, `baseRange=2`, `currPage`를 확인했다. 목포 기준 실제 응답의 거리 최댓값은 1.998km였다. 최근 전국 갱신은 전국 키워드 결과를 주소로 분류한 것이며 지역 전체 격자검색은 아니었다.

이번에는 검색어 없이 모든 주변 업종을 수집한 다음 연료 상호·연간 연료 후보·등록된 주유소 주소를 대조한다. 업종이 확인되지 않은 법인명과 같은 주소의 다른 점포를 자동으로 주유소로 확정하지 않는다. 초기 전체 호출 간격 0.5초·3개 연결에서 오류 관측 후 1초·1개 연결로 낮췄다. 후속 지역 실행기의 기본값도 1초·1개 연결이다. HTTP 401·403·429 및 본문에 명시된 접근 차단은 재시도하지 않는다.

## 재현과 검증

`scripts/grid_search.py plan`으로 계획을 만들고 `scan`으로 수집한다. `output/grid_cache/`에 지점별 전체 응답을 원자적으로 저장한다. 중단 후 같은 명령으로 완료 지점을 재사용한다. 계획 해시가 다르면 캐시를 섞지 않는다. 첫 페이지·전체 페이지 수·총 응답 수·중복 ID·좌표 반경을 검사하며 한 지점이라도 실패하면 완결된 스냅샷을 쓰지 않는다.

공개 이력에는 지점별 중심, 조회 시각, 페이지/건수, 결과 해시와 연료 관련 후보를 남긴다. 대량의 일반 가맹점 원문은 로컬 캐시에 보존한다. 전남에서 새로 확인한 항목만 관측일을 갱신하고 다른 지역의 기존 확인일을 유지한다. 격자에서 안 나온 기존 기록은 삭제나 가맹 해지로 판정하지 않는다.

## 실행 결과: 전남 부분 수집, 사이트 차단으로 중단

전남 2,810개 계획 지점 중 415개(검색 지점 기준 14.77%)의 응답·페이지 확인을 마쳤다. 2,395개는 미완료다. 정상 응답의 지역 주소를 기준으로 중복 제거한 전남 가맹점은 1,542곳이다. 현재 수집 범위는 순천시 177/177개, 강진군 116/116개 계획 지점을 포함한다. 다른 시군은 일부 경계에 걸친 지점만 조회됐으며, 지점은 시군 간 중복될 수 있어 시군별 수를 합산하면 안 된다. 격자 완료율을 토지 면적이나 전체 가맹점 발견율로 해석하지 않는다.

전체 응답을 연료 상호·연간 명부·공식 주유/차량용 가스충전 등록 주소와 대조한 결과 후보는 기존 순천주유소(`14077200010`)·호남주유소(`14077200045`) 2곳이다. 신규 차량 주유소 후보는 0곳이다. 순천 현대주유소의 현재 가맹 연결도 새로 확보하지 못했다. 가맹 해지나 폐업으로 판정하지 않았다. 지도는 전국 표시 203곳, 전남 22곳, 고유 대기 18곳을 유지하며 가맹·좌표·확인 날짜를 이번 부분 수집으로 덮어쓰지 않았다.

초기 HTTP 400은 동일 요청이 재조회에서 정상 응답해 일시 오류로 판단했다. 오류 본문 기록을 추가한 뒤 `Request Blocked` 문구를 확인했고 모든 추가 조회를 중단했다. 차단을 인지하기 전 기존 공통 클라이언트가 HTTP 400을 일반 오류로 재시도하던 문제를 수정했다. 이제 명시적 차단 본문은 즉시 `PermissionError`로 중단하며 자동 재시도·연결 재설정을 하지 않는다. 기록된 blocked 캐시를 다시 실행해도 네트워크 요청 전에 멈춘다. 사이트의 정상적인 허용 접근이 회복됐다는 근거 없이 재개하지 않는다.

별도로 16개 후속 지역의 격자 계획과 순차 실행기를 준비했지만 실제 후속 지역 검색은 시작하지 않았다. 순서상 전남을 먼저 끝내며 서울은 마지막이다. 모든 수집 프로세스는 종료했다. 클라우드나 예약 작업을 생성하지 않았다.
