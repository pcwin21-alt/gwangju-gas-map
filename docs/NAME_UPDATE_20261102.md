- 화면 H1·브라우저 탭·검색 설명·OG 제목/설명·한영 전환 후 제목·공유 미리보기 이미지를 같은 이름으로 맞춘다.
- 제목: ~~전국 온누리 주유소 지도~~ → **전국 주유소 할인 지도**.
- 설명: ~~전국 온누리 · 광주상생카드 가맹점~~ → **온누리·광주상생카드 사용처와 주유 가격을 한눈에.**
- 기능, 가맹점 자료, 가격 계산, 지도 조작, 필터, 기존 모바일 레이아웃은 유지한다.
- 영문 제목은 'Korea Fuel Discount Map'. 기존 문구의 번역 키는 호환을 위해 남기되, 현재 제목/설명은 새 키를 사용한다.
- 기존 공유 이미지에 '광주 주유소 지도' 문구가 남아 있어 새 이름으로 교체한다. 원본 thumbnail.png는 보존하고 별도 파일을 사용해 캐시와 원본 보존을 함께 처리한다.
