# 지도 상세·목록 시각 정리

사용자 과업: 지도/목록에서 주유소를 고르고, 결제 가능 범위와 실제 가격을 읽은 뒤 기존 지도 앱 길찾기 또는 경유 기능을 이용한다. 이번 요청은 중복 UI 제거와 실제 사례에 근거한 시각 정리다. 새로운 UX 흐름은 설계하지 않는다.

## 근거와 적용

- 사용자 제공 화면: `(주)동행` 상세의 복사 아이콘, 미확인 거리·유가 자리, 긴 조회 태그와 하단 근거 반복.
- 원 인터뷰 게시자의 [앱인토스 인터뷰](https://maily.so/josh/posts/2qzpel5jo4x)와 토스 제공 [사례 슬라이드](https://cdn.maily.so/du/josh/202610/1793244300094979.png)의 ‘최저가 주유소’ 실제 화면을 확인했다. 기사 이미지의 출처 표시는 토스 앱인토스다.
- 관찰: 지도 중심 구성, 작고 밝은 가격 말풍선, 굵은 가격 숫자, 절제된 강조색, 간결한 선택 바.
- 적용: 흰색/다크 테마 패널, 얇은 중립색 경계, 이름·주소·가격의 명확한 크기 차이, 차분한 결제 라벨과 지도 링크. 기존 네이비 브랜드와 지도 엔진을 유지한다.
- 적용하지 않음: 이미지에 나온 유종 칩·최저가 순위·광고·가격 핀 체계를 새로 추가하지 않는다. 정지 화면에서 앱의 전체 이용 흐름을 추정하지 않는다. 토스 로고·폰트·그래픽을 제품에 복제하지 않는다.

## 제거와 보존

- 상세의 이름·주소 복사 버튼, 위치 확인 전 거리 틀, 가격 미확인 자리, 중복 조회·위치 근거 설명을 제거했다. 알려진 실제 거리와 유효 가격은 표시한다.
- 결제 유형과 확인일은 각각 한 번만 표시한다. KB국민카드 조회 근거는 ‘온누리 KB국민카드’로 한정한다. 최근 미확인 상태와 공식 자료 기준일은 숨기거나 조회 확인일로 바꾸지 않는다.
- 카카오맵/네이버지도는 기존 직접 링크로 제공한다. 추가된 ‘여기로 길찾기’ 펼침 단계를 제거했다. 경유 기능은 원래 지원되는 주유소에만 기존 동작으로 연결한다.
- 목록의 긴 근거 행, 중복 정렬·집계 문구, 내부 후보 조사 대기 목록을 제거했다. 범위·정렬·페이지 추가·자료 확인 정보와 빈 결과 복구는 유지한다.
- ‘결과 보기’는 기존 지도 맞춤 동작을 드러내도록 ‘결과 위치’로 명칭만 변경했다.
- 지도 이동·확대, 지역·결제·유종 선택, 경로 계산, 상세 닫기 시 선택 행·스크롤 복귀는 기존 계약을 유지한다.
- STATIONS / PRICES / PRICE_INFO / MERCHANT_STATUS / NATIONAL_PENDING 내장 데이터와 조사 근거는 변경하지 않았다.

## 검증 기록

구현 후 Node/Python 검사, 사이트 빌드와 diff 검사, 데이터 동일성 검사를 실행한다. 브라우저 검증·공개 배포 결과는 확인 후 아래에 추가한다. 실제 휴대전화·GPS·외부 내비 앱 실행과 브라우저 검증은 구분한다.

라우팅: 공통 AGENTS/00_START_HERE와 기존 프로젝트 계약, codex-delivery-loop + toss-ux-principles 적용. 기존 시각 토큰·접근성 기준을 사용했다. 사용자 요청 범위의 표시 정리이며 새 서비스 기획·앱인토스 SDK/입점·계정 변경은 포함하지 않는다.
