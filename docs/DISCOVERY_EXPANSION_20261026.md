# 온누리 주유소 추가 발견 경로 — 2026-10-26

## 결론

이전 조사에는 두 한계가 있었다. 이미 선정된 미확정 후보를 재검증하는 데 집중했고, 상권자료에서 LPG 업종 이름을 실제 원문과 다르게 비교해 충전소가 빠졌다. 따라서 기존 후보에서 추가 확정이 적었다는 사실을 전국의 실제 가맹 주유소가 적다는 결론으로 일반화할 수 없다. 반대로 아래에서 늘어난 조사 대상 수 역시 온누리 가맹점 수가 아니다.

이번에는 기존 후보 ID와 무관하게 전체 상권자료·전체 과거 명부·기존 격자 원문을 다시 비교했다. 온누리 실시간 서버 요청은 0건이며, 확정 지도와 공식 검색 확인일은 변경하지 않았다.

### 전남 우선 신규 조사 대상

1. **동부주유소 / 무안군 해제면 현해로 1441**: 2021 지류 명부에서 해제면5일시장 소속. 2026 상권자료의 상호·도로명주소가 일치한다. 현재 온누리 등록과 결제 유형을 확인할 가치가 가장 높다.
2. **해제주유소 / 무안군 해제면**: 2021 명부는 신정리 21-2, 2026 동명 업체는 현해로 1699·신정리 22-3. 같은 마을이지만 지번이 다르므로 동일 영업장 여부부터 해결한다.

두 곳은 2026-07-31 전체 연간 가맹 파일에서 같은 상호가 발견되지 않았다. 이것만으로 폐업·탈퇴를 단정하지 않는다. 지도 확정 지점으로 승격하지 않고 별도 발견 후보에 저장했다.

전남 밖에는 공열·고래(전북), 일선교(경북), 화성제일(대구) 등의 과거 주소 연결이 있다. 충주 제일주유소 주소에는 현재 다른 상호가 있어 가맹 승계로 간주하지 않는다. 전남 → 광주 → 전북 → 경남 → 경북 → 부산 → 대구 → 울산 → 충남 → 충북 → 대전 → 세종 → 강원 → 제주 → 경기 → 인천 → 서울 순서를 유지한다.

## 추가로 유망한 경로

**연간 명부 기준일 뒤 새로 지정된 상점가를 역추적한다.** 현재 연간 파일 기준일은 2026-07-31인데, 장성군에는 2026-08-04 골목형상점가 지정 고시(제2026-119호)가 있다. 따라서 연간 파일만 계속 재검색하면 이후 신규 등록 가능 구역을 놓칠 수 있다. 지정 고시의 구역도·점포 명부에서 주유소 주소를 찾고, 현재 가맹 여부를 별도로 확인하는 순서가 합리적이다. 이번에는 고시 본문 존재와 날짜까지 확인했고 첨부 구역도 분석은 아직 하지 않았다. 구역 안에 있다는 사실 자체가 개별 점포의 가맹을 뜻하지 않는다.

**실제 결제 후기·주유소의 안내문은 후보 발견에 사용한다.** 상호·주소·게시일·지류/디지털을 함께 확보해야 하며 검색 요약만으로 확정하지 않는다. 이번 네이버 블로그 리서치 도구의 소량 검색은 HTTP 403으로 실패했다. 일반 웹 검색에서는 두 무안 후보의 현재 온누리 이용을 확인할 신뢰할 만한 근거를 얻지 못했다. 실패를 빈 결과/미가맹으로 해석하지 않는다.

**주소를 포함한 최신 공식 파일 확보가 근본적 대안이다.** 기존 문서에 준비한 기관 제공 요청안을 사용할 수 있다. 기관·상인회·점포에 실제 연락하거나 제출하지 않았다. 지도/가격 서비스와 인허가 자료는 실제 영업장 후보를 찾는 용도이며 온누리 가맹 증거를 대신하지 않는다.

## 검증과 재현

Python 79개 테스트 통과. LPG 업종 코드, 가정용 연료 제외, 띄어쓴 도로명 오인 방지, 시·구 식별, 기존 조회 재사용 및 남은 좌표 전체 포함을 검증했다. 도로명에서 `거제중앙로 19길 13`을 `거제중앙로 19`로 잘못 붙이는 발견용 주소 비교도 수정했다. 첫 시도 오탐 결과는 유효 결과로 집계하지 않고 로컬에만 보관했다.

- `discover_bulk_candidates.py`: 전체 업종 추출 및 전체 연간 가맹 파일 대조.
- `discover_address_candidates.py`: 전체 주소·축약명 대조.
- `discover_historical_fuel.py`: 전체 과거 가맹 파일에서 발견 후보 추출.
- `plan_fuel_centers.py`: 네트워크 요청 없이 기존 캐시를 활용한 조회 중심점 계획.

원자료 해시·기준일은 각 결과 JSON에 기록했다. 전체 차량 연료 인덱스(약 9 MB)와 다운로드 원문은 로컬에 보관하고, 검토 결과 및 301개 조회 중심점 계획은 저장소에 남겼다. 지도 203곳(전남 22곳), 대기 17곳은 유지했다. 전국 격자 전수조사나 현재 결제 실증 완료로 표시하지 않는다.
