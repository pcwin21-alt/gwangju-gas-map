- 가격 연결은 station_id. UID의 상호·도로·건물번호·시군구·광역 지역을 재확인하고, 날짜 없는/잘못된/3일 초과 가격은 공개 가격에서 제외한다.
- 기존 가격 캐시는 새 schema 2 검증 없이 재사용하지 않는다. 로컬에는 OPINET_API_KEY가 없으므로 기존 GitHub Actions 환경에서 재수집을 실행했다. 마지막 실행 39952849920은 작업 자체는 완료됐지만 현재 ID 후보 0개·검증 가격 0개로 끝났다. API 빈 응답 및 요청 실패가 발생했으며 원인(인증·한도·원천 응답)은 확정하지 못했다. 따라서 현재 가격은 '가격 미확인'으로 표시한다. 과거의 유종 오연결 가격을 복원하지 않는다.
- 가격 수집 일 1회, 최대 200 요청/일의 영속 시도 장부. 실패 요청도 계산하며 인증·응답 실패 반복은 5회에서 중단한다. 원천별 갱신과 `_site` 허용 목록·쓰기 concurrency 유지.
- 지도 SDK가 로드되지 않으면 공개 목록·검색·필터와 외부 길찾기로 복구한다. 정확 위치·개인 경로를 공유 URL에 넣지 않는다.

## 검증과 한계

- Python 23개 및 Node 17개 검사 통과. 동명 지점·타지역 오연결·유종 코드·불명확 좌표·지류 전용·stale 경유 제외를 포함한다.
- localhost:8080 실제 Kakao 지도에서 경기 3곳 → 가평군 1곳, 신규 현리주유소 주소·좌표와 길찾기 URL을 확인했다. 서울 빈 결과 및 대기 목록, 디지털 필터를 확인했다.
- 390×844 및 320×740 브라우저에서 문서 scrollWidth가 viewport와 같고 지도 표시 공간이 남는 것을 측정했다.
- 실제 Android/iOS 내비 앱 실행, 이용자의 현장 결제 성공, 미확인 후보 전수 주소 확인은 미검증.
- 배포 작업 39952849012 및 Pages 게시 39952870049 성공 후 실제 공개 화면에서 제목과 전체 지도 162곳을 확인했다. 실제 가격 재수집은 위와 같이 미완료 상태이며 배포 성공과 구분한다.

- 공개 주소에서 경기 지역 신규 지점 3곳, 지점 상세·내비 링크·한영 전환 및 모바일 화면을 확인했다. 기사식당·편의점 가맹을 주유 거래에 전이하지 않도록 기존 기록도 재검토했다.
