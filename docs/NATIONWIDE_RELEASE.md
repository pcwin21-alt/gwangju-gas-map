## 구현

- 시도·시군구, 지류/디지털, 차량 유종 필터, 공개 URL 필터 복원과 뒤로가기, 지도와 동기화된 목록·더보기·미확인 후보 목록.
- 광주상생카드와 기존 경유/내비 링크·한영 기능 유지. stale 온누리 기록은 경유 추천 제외.
- 잘못된 경유/LPG 매핑 수정: B027 휘발유, D047 경유, B034 고급휘발유, K015 LPG. [공식 상세정보 계약](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=1).
- 가격 연결은 station_id. UID의 상호·도로·건물번호·시군구·광역 지역을 재확인하고, 날짜 없는/잘못된/3일 초과 가격은 공개 가격에서 제외한다.
- 기존 가격 캐시는 새 schema 2 검증 없이 재사용하지 않는다. 로컬에는 OPINET_API_KEY가 없어 실제 재수집을 수행하지 못했다. 기존 GitHub Actions 환경에서 별도 실행·검증해야 한다.
- 가격 수집 일 1회, 최대 200 요청/일의 영속 시도 장부. 실패 요청도 계산하며 인증·응답 실패 반복은 5회에서 중단한다. 원천별 갱신과 `_site` 허용 목록·쓰기 concurrency 유지.
- 지도 SDK가 로드되지 않으면 공개 목록·검색·필터와 외부 길찾기로 복구한다. 정확 위치·개인 경로를 공유 URL에 넣지 않는다.
