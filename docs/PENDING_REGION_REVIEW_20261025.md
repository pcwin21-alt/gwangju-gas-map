# 미확인 후보의 지역 분류 후속 검토 — 2026-10-25

## 실행 계약과 라우팅

전남부터 남은 후보의 추가 근거를 확인하고, 가맹 여부나 주소를 추측하지 않은 채 지도와 검토 목록의 정확도를 개선한다. 기존 17개 지역 순서와 공식 확인 기준을 유지한다. 이번 범위는 대기 후보의 지역 혼재 및 상호·상점가 불일치 검토이며, 33개 후보 모두의 새 가맹 확인을 완료했다는 뜻은 아니다.

입력은 오늘 수집한 공식 검색, 연간 가맹점 파일, 공공 주유소 등록자료, 공식 시장 주소 자료다. 출력은 지역 근거 장부, 지역 분리 로직, 공개 대기 목록과 검사·배포 증거다. 수락 조건은 전남·광주 중복 표시 해소, 원문 지역 보존, 주소·좌표·결제수단·가맹 확인 상태 불변, 불충분·충돌 근거의 미확정 유지다.

공유 하네스의 Project Execution·Source·Global Eval과 기존 실행 계약을 이어서 적용했다. `localdata-business-status` 스킬을 인허가 확인에 활성화했으나 공식 서버 접근 오류로 결과는 `unavailable`이다. 기존 UI 구조·디자인·문체 변경, 신규 유료 서비스, 연락 발송, 하네스·메모리 변경, 멀티에이전트는 제외했다.

## 확인한 문제와 반영

연간 가맹점 파일의 `전남광주`를 그대로 쓰던 미확인 6개 후보가 전남과 광주 양쪽 필터에 표시됐다. 광역지역조차 확정되지 않은 후보가 각 지역에 확정된 후보처럼 합산되는 문제였다.

| 후보 | 분리 결과 | 근거 |
|---|---|---|
| 현대주유소 · 웃장 | 전남 | 전국전통시장표준데이터의 웃장 주소: 순천시 |
| 청우에너지 · 매월동상인회 | 광주 | 같은 상점가의 현행 가맹점 2곳 주소가 모두 광주 서구 |
| 서부에너지 · 맛조이상인회 | 광주 | 같은 상점가의 현행 가맹점 2곳 주소가 모두 광주 서구 |
| 금호석유 · 송정매일시장 | 광주 | 전국전통시장표준데이터의 송정매일시장 주소: 광주 광산구 |
| ㈜동행 · 신창동가구의거리일번국도상점가 | 지역 미확정 | 정확히 일치하는 상점가의 공식 주소 근거 부족 |
| 다올에너지산업 · 같은 상점가 | 지역 미확정 | 이름이 비슷한 별도 상점가·지점을 동일 업체로 단정하지 않음 |

원문 `source_region=전남광주`는 보존한다. 공식 시장명은 공백만 정규화하고, 일부 단어·명칭 순서·괄호를 임의로 바꾸어 합치지 않는다. 시장 등록자료의 정확한 이름과 주소, 또는 서로 다른 현행 가맹점 2곳 이상의 일치하는 시장명·지역으로 광역지역만 판단한다. 지역이 충돌하거나 근거가 부족하면 전국 목록의 `지역 미확정`으로 표시한다.

**시장 주소는 주유소 주소가 아니다.** 이번 보강으로 후보의 상세주소·좌표·결제수단·현행 가맹 상태를 확정하거나 지도에 새 지점을 추가하지 않았다. 전체 지도 202곳, 현행 온누리 확인 168곳, 대기 33개 후보(원천 34행)는 유지한다. 지역별 대기는 전남 6→1, 광주 18→15, 전국에서 확인 가능한 지역 미확정 2곳으로 정리된다.

## 추가 조사와 한계

- [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do) 1,393행을 내려받아 전체 행수를 대조했다. 웃장·송정매일시장의 해당 기준일은 2025-11-10이다.
- [공식 온누리 검색](https://www.onnuri.gift/place)에서 상점가를 확인하기 위한 추가 상호 검색 7조건을 수행했다. 원천 쿼리와 반환 행은 `output/market_region_queries_20261025.json`에 저장했다. 매월동 근거는 오늘 10:16의 기존 공식 검색에서 확인했다.
- [골목형상점가 현황](https://www.data.go.kr/data/15118622/fileData.do) 264행과 [상점가 현황](https://www.data.go.kr/data/15118623/fileData.do) 349행도 대조했으나 신창동 후보의 정확한 상점가 이름은 발견하지 못했다. 미발견을 폐쇄·해지로 해석하지 않는다.
- LOCALDATA 순천 석유판매업·석유 및 석유대체연료 판매업 파일 조회는 실패했다. 파일 다운로드 HTTP 400, 원천 안내 페이지 HTTP 403으로 인허가 근거를 새로 확보하지 못했다. 인증 우회는 시도하지 않았다.
- 일부 검색 결과는 시장 대표 주소를 개별 주유소 주소로 표시하거나 상호가 비슷한 다른 지역 업체를 제시했다. 해당 제3자 결과는 지도 추가 근거에서 제외했다.
- `output/market_region_evidence.json`은 시장의 광역지역을 분리하는 근거만 저장한다. 수집 원천의 전수성이나 미확인 지점의 현재 가맹 여부를 보장하지 않는다.
