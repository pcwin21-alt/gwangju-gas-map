# 온누리 혜택·정책 안내와 정기 점검

2026-11-04 KST. 사용자가 요청한 작은 할인 안내 → 최근 정책·적용 일정·공식 가입 안내 흐름이다. 기존 지도와 5종의 가맹점·유가 데이터, 확인일과 자동 조사 중단 합의는 유지한다.

## 화면과 정보 기준

지도 아래의 확대·위치 조작 사이에 작은 `온누리 기본 7%` 버튼을 둔다. 새 상단 줄을 만들지 않는다. 기간 한정 공지가 있으면 별도 점과 접근성 이름으로 알리고, 누르면 기본 할인·행사·추진안·가입 안내·공식 출처를 팝업에서 본다. 목록·상세·경유창이 열리면 지도 위의 안내는 숨기며 더보기의 `온누리 혜택·정책`으로 다시 접근할 수 있다. 닫기·ESC 후 원래 버튼으로 복귀하고 지도 확대·이동을 다시 맞추지 않는다.

처음 제안한 ~~현재 온누리 7%~~를 **디지털 온누리 기본 구매할인 7%**로 구체화했다. 주유소 판매 단가 할인이나 지류·모든 결제 수단에 같은 혜택이 적용된다는 뜻이 아니다.

| 구분 | 확인한 내용 | 실제 적용 시점의 처리 |
| --- | --- | --- |
| 기본 디지털 구매할인 | 7%. 10월1일 원문 표와 10월27일 행사 발표의 평시 기준 | 마지막 공식 확인일 표시. 개인의 현재 구매 가능액·실제 적용률 보장 아님 |
| 코그페 특별판매 | 7%→10% 특별할인 공지 | 2026-11-02~11-06. 전체 행사 10/29~11/15와 구분. 구간·한도·예산·정확한 종료 시각을 추정하지 않음 |
| 차등 할인·환급 | 전통시장 5%+5%, 지방 골목상권 5%+3%, 수도권 골목상권 5%+0% | 원문 표는 `’27년 ... (안)`. 2027년 추진안으로 보존하며 정확한 시작일 미확인. 시간이 지났다는 이유로 활성화하지 않음 |

가입은 공식 디지털온누리 앱에서 진행한다. 웹에는 개발자 KOMSCO/한국조폐공사를 확인한 Android·iPhone 공식 스토어 안내 링크를 제공한다. 지도에서 가입·충전·결제를 받지 않는다. 앱인토스 빌드는 [서비스 오픈 정책 2-2](https://developers-apps-in-toss.toss.im/intro/guide.md)에 따라 앱 마켓 링크를 번들에서 제거하고 가입·이용 순서와 공공기관 정책 원문을 제공한다. 기존 출시본에 이 새 기능이 생긴 것으로 보고하지 않는다.

## 데이터와 갱신

- 정본: `assets/onnuri-policy.json`. 발표일, 시행일, 종료일, 추진 상태, 기본 구매할인, 공식 출처와 실제 확인일을 별도 필드로 관리한다.
- `scripts/build_policy_data.py`: 출처·날짜·추진 상태를 검사하고 `assets/onnuri-policy-data.js`를 생성한다. 웹과 토스 빌드는 같은 검사를 거친다.
- `assets/onnuri-policy-core.js`: 한국 날짜로 시작 전·기간 한정·기간 종료를 구분한다. 추진안은 날짜만으로 시행 중이 되지 않는다.
- 향후 기본 구매할인 변경의 정확한 시행일이 공식 확정되면 해당 공지에 `kind=confirmed`, `affects=digital_base`, `rate`, `startsOn`을 기록한다. 검증된 확인 기간 안에서만 한국 날짜의 시작일에 새 기본값을 적용한다. 소비환급·총혜택·한시 특별판매를 이 필드로 넣지 않는다. 현재 2027년 추진안에는 이 필드를 적용하지 않았다.
- 공식 확인 후 7일을 넘기거나 확인일이 미래이면 현재 할인 숫자를 숨기고 `온누리 혜택·정책`으로 표시한다. `recheckBy`는 연말 재점검을 강제하는 표시 기준이며 실제 정책 종료일을 주장하는 필드가 아니다.
- 웹은 같은 사이트의 JSON, 토스 후보는 `https://pcwin21-alt.github.io/gwangju-gas-map/assets/onnuri-policy.json`을 시작 시 1회 읽는다. `새로 확인`은 이 게시 자료를 다시 읽는 행동이며 정부 원천을 실시간 조사했다는 뜻이 아니다.
- 네트워크 실패·잘못된 형식·더 오래되거나 미래인 확인일이면 내장 확인 자료를 유지하고 상태를 표시한다. HTML 문자열을 실행하지 않으며 출처는 허용한 HTTPS 호스트만 사용한다. 요청에 위치·검색어·식별키·자격증명·리퍼러를 넣지 않는다.
- 매일 한국시간 오전9시 자동 점검(`automation-7`, 온누리 정책·할인 변동 점검)을 설정했다. 새 공식 공지·정정·시행일을 확인하고 검증된 정책 정보만 갱신·검사·웹 배포·재확인한다. 기존 가맹점 발굴 방법 검토(`automation-5`)와 별개이며 중단한 원천 수집을 재개하지 않는다. 자동화 실행 전에도 날짜가 지난 행사는 화면에서 종료로 분류한다.

## 검증과 운영 기록

- 날짜·한시 종료·추진안 비활성·확인 노후화·부정 URL의 회귀 검사는 2026-11-04 고정 표본으로 수행한다. 실제 정본의 다음 정책 변경이 이 역사 표본을 덮어쓰지 않는다.
- 정본과 내장 자료 일치, 토스의 앱 마켓 URL 제거, 기존 5종 지도 데이터 보존을 검사한다.
- 실제 브라우저·배포·새 토스 후보 상태는 `output/onnuri-policy-20261104/verification.json`에 기록한다. 로컬 빌드 성공과 토스 콘솔 출시를 구분한다.
- 확인된 변화가 없으면 과거 소식을 새 정책으로 재포장하지 않는다. 공식 근거가 부족하거나 상충하면 마지막 확인 자료와 보류 이유를 남긴다.
