# 작은 지역 버튼과 선택 팝업

요청: 상단을 크게 차지하는 지역 선택 바를 버튼과 팝업으로 바꾸고 광주를 기본 지역으로 둔다.

계약: 검색창·현재 지역 버튼·필터를 한 줄에 놓고 결과 수와 조건 요약을 아래 한 줄로 표시한다. 현재 지역을 누르면 지역 선택 모달이 열리고 지역을 선택하면 기존 필터 경로로 적용 후 닫힌다. 닫기/Escape/바깥 클릭은 필터·지도 줌을 바꾸지 않는다. 다시 같은 지역을 눌러도 불필요한 줌 변경이 없어야 한다. 포커스는 지역 버튼으로 복귀한다. 기본 진입은 광주, 기존 `region=전남` 등의 링크와 `region=all`의 전국 선택은 복원해야 한다.

구현: 원래 regionSelect는 모달 내부의 숨긴 상태 입력으로 유지한다. 지역 버튼이 change 이벤트를 전달해 기존 지역/검색/결제수단·목록·URL 처리를 재사용한다. 전국은 기본 광주와 구분하기 위해 URL에 `region=all`을 명시한다. 기본 진입과 전체 초기화는 광주를 선택한다. 가맹점 데이터와 지도 이벤트는 변경하지 않는다.

레이아웃: 입력·버튼 16px/1.5, 모달 제목 18px/1.5/700, 메타 14px/1.5, 모든 새 버튼 최소 높이 44px. 지역 모달은 3열, 320px에서도 가로 스크롤 없이 선택하도록 설계한다. 테마 토큰을 재사용하고 현재 지역은 색과 aria-pressed로 구분한다.
