# 상세창 컬러 팔레트 — 2026-11-02

사용자 요청: 첨부된 주유소 상세창을 기준으로, 팔레트에서 가져온 차분하고 고급스러운 색 조합을 우리 서비스에 맞춘다.

## 선택과 근거

[Radix Colors 팔레트 구성](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette)의 Sand·Indigo·Jade·Sage 색상 단계를 사용한다. 원색은 공식 [light.ts](https://github.com/radix-ui/colors/blob/main/src/light.ts)와 [dark.ts](https://github.com/radix-ui/colors/blob/main/src/dark.ts)를 2026-11-02에 확인했다. 라이브러리 설치나 외부 CSS 로딩을 추가하지 않고 선택한 sRGB 값만 기존 상세창 토큰에 연결했다.

- 관찰: 기존 화면에는 푸른 보조 글자·옅은 청색 버튼·크림 가격 행·녹색 주요 버튼이 혼재했다. 전체 브랜드의 남색은 유지하되 상세 정보 안의 색상 역할을 좁힌다.
- 가설: 따뜻한 중립 표면을 주로 쓰고, 결제 맥락과 주 행동에 녹색을 집중하면 정보 우선순위가 분명하고 차분하게 느껴질 것이다. ‘고급스럽다’는 효과는 설계 판단이며 사용자 선호 조사로 검증한 사실이 아니다.
- 배분: 6:3:1을 후보로 검토했지만 정보 카드의 실제 구성에서는 중립 면을 넓게 두고 남색은 글자, 녹색은 배지·주 행동에 한정했다. 면적 비율을 측정했다고 주장하지 않는다.
- 제외: 지도 핀의 결제수단 구분, 경고/오류 상태색, 전역 테마 전환, 글자 크기·배치·동작·결제/가격 데이터는 바꾸지 않는다. 토스 시각 자산은 사용하지 않는다.

기존 브랜드 남색 `#233E78`과 계열이 이어지는 짙은 Indigo 12를 정보색으로 골랐다. 초록색의 심리 효과나 신뢰 상승을 입증한 것으로 쓰지 않는다. 색의 의미는 결제 설명·유종 이름·버튼 문구와 함께 전달한다.

## 구현·검증 계약

입력은 기존 상세창·팔레트 원천·사용자 이미지, 행동은 `assets/responsive-ui.css`의 상세창 전용 색 토큰 정리, 출력은 같은 구조의 라이트/다크 상세창이다. 수락 조건은 색 역할 일관성, 본문/버튼 명암 대비 4.5:1 이상, 작은 화면·큰 글자에서 가로 넘침 없음, 선택·닫기·경유 흐름 보존이다.

하네스: canonical AGENTS/Skill Router/Brain 및 최소 작업 계약은 always, Project Execution·Toss UX·codex-delivery-loop·KRDS·변경 범위 Global/Software UX/Design Gate는 active. Source는 팔레트 관측과 우리의 선택·가설을 분리한다. 신규 기능·전면 개편·앱인토스 제출·가맹점 조사·개인 메모리 갱신·멀티에이전트는 제외한다. 관련 스킬을 실제 읽고 기존 검수 생성기와 브라우저를 사용했다.

검증: 기존 테마·상세·핀·목록 회귀 검사 18개 통과. 로컬 렌더 320×740 / 390×844 / 1280×800에서 라이트·다크와 글자 100%·200%의 12조합을 확인했다. 카드의 화면 이탈과 페이지 가로 넘침은 없었다. 제목·주소·확인일·배지·유종·가격·보조 버튼·주 버튼의 계산 색상 쌍은 모두 4.5:1 이상이었다. 라이트 주 버튼의 hover `#208368` 위 흰색은 4.66:1, 다크 hover `#C3E9D7` 위 글자는 11.13:1이다. 추가 최종 규칙으로 다크 주소·확인일도 Slate 11에 통일했다.

로컬 검수 화면은 예시 데이터이며 지도 SDK·GPS·전송을 실행하지 않는다. 공개 배포본의 최종 확인은 후속 기록으로 남긴다. 실제 휴대전화의 물리 화면·색 재현이나 선호도 검증을 했다고 표현하지 않는다.
