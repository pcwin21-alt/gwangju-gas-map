# 지도 기본 메뉴와 경유 검색 간소화

## 작업 계약과 라우팅
- 요청: 기본 메뉴를 줄이고 경유 주유소 찾기를 간소화한다.
- 이용자/산출물: 모바일 중심의 전국 가맹 주유소 지도 이용자 / 기존 공개 지도 UI 수정.
- 가설: 첫 화면을 검색·지역·내 위치로 줄이고 경유 검색을 목적지부터 시작하면 선택 부담을 줄인다. 실제 사용성 향상은 사용자 피드백으로 확인할 가설이다.
- 수락: 기본 상세 필터 접힘, 적용 조건 표시, 기존 검색·필터·더보기 기능 유지, 목적지 선택 전 GPS 미요청, 출발지 수동 변경, 모바일/PC 렌더 및 회귀 검사.
- 입력: 기존 공개 UI, output/map.html, assets, 현재 사용자 지시. 가맹점/가격 데이터 변경은 범위 밖.
- always: canonical identity_harness AGENTS/00_START_HERE/Skill Router, Brain, Source, Eval Global.
- active: Project Execution Agent, codex-delivery-loop, KRDS Web Typography and Information Hierarchy, computer-use. 관련 파일을 읽고 설계·구현·검수에 적용.
- reference: 기존 지도 화면과 데이터/URL 처리. 별도 외부 디자인 모방 없음.
- excluded: 신규 제품 기획, 콘텐츠 문체, 신규 데이터 조사, 멀티에이전트, 개인 식별정보 수집.
- drift: discovery index보다 실제 canonical root와 저장소 파일을 우선. harness 자체 수정 없음.

## 화면 결정
- 기본: 제목·더보기, 검색·결과 수, 시도·내 위치·필터, 경유 찾기.
- 필터 펼침: 결제수단·온누리 유형·유종·시군구·조건 초기화. 접혀도 적용 조건과 개수 표시. Escape로 닫고 필터 버튼으로 포커스 복귀.
- 더보기: 가격 순위, 사용법, 언어 전환, 전체 초기화, 내보내기 및 기존 보조 기능.
- 경유: 목적지 검색 → 결과 선택 → 같은 버튼으로 경유 후보 비교. 출발지는 내 위치 기본값, 요청은 비교 실행 시에만. 출발지·조건은 접힌 상세 영역에서 수정.
- 첫 경유 열기에 지도 결제/유종 조건을 읽고 이후 사용자의 경유 설정을 유지. 전체 결제에서 특정 온누리 유형이 적용돼 있으면 경유 결제는 온누리로 설정. 경유에서는 전체 결제 선택 시 온누리 유형 제한 해제.
- 설명 중복 삭제, 계산 한계와 외부 경로 서비스 안내는 펼침 항목으로 유지. GPS 실패 시 수동 출발지 영역 자동 열림.
- 본문 16px/1.5/400, 제목 18px/1.5/700, 조작 16px/1.5, 메타 14px/1.5. 모바일 H1은 단일 지도 도구 제목으로 16px/1.5/700. 44px 이상 터치 영역.

## 검증 기록
- Node 24개, Python 100개 통과. 신규 4개는 목적지 선택과 위치 요청 분리, 재열기 설정 유지, 위치 권한 거부 복구, 위치 대기 중 목적지 변경 취소를 검증.
- JS 문법 검사, git diff --check, 정적 사이트 생성 통과.
- 로컬 390×844: 지도 SDK 미로드 시 목록 대체 화면, 상세 필터 열기/선택/닫기 및 적용 조건 유지 확인. 가로 넘침 없음.
- localhost와 127.0.0.1은 SDK 미로드. 공개 배포 2f51ff6에서 실제 SDK로 목포역 검색/선택, 광주역 수동 출발지 지정, 경유 후보 24개 도로 계산과 결과 5개를 확인했다.
- 공개 390×844: 전남 → 온누리·휘발유/경유·나주시 6곳, Escape 닫기, 뒤로가기 조건 복원, 상세 조건 초기화(전남 유지 28곳), 더보기의 가격 순위와 사용법 작동 확인.
- 공개 320×640 영어: 경유 결과에서 경로 수정으로 돌아오기, 입력·버튼·조건 표시 및 가로 넘침 없음 확인. 한국어 복귀, 전체 초기화(216곳), 1280×900 기본 지도 확인.
- GPS 위치 권한 허용, 실제 휴대폰 내비 앱 실행은 이번 검사 대상에서 제외. 공개 장소를 수동 출발지/목적지로 사용한다.
- 첫 UI 배포 및 연결 검사 성공: GitHub Actions 40966942763, 40966942639, 40966942516, Pages 40966963478.
- 사용법 안내도 실제 메뉴 위치에 맞춰 수정. 데스크톱에서는 검색과 지역 도구를 한 줄로 줄임.
