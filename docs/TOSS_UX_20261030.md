# 주유소 선택·길찾기 UX 개선

계약: 온누리 등 결제 유형에 맞는 주유소를 비교하고 길찾기로 이어지는 흐름을 개선한다. 기존 카카오 지도와 가맹점·가격 데이터를 유지한다. 앱인토스 SDK 전환·콘솔 등록·경로 서버 교체는 이 변경에 포함하지 않는다.

변경:
- 목록은 이름순, 위치 확인 후 직선거리순을 지원한다. 실제 위치가 없으면 가까운 순을 사용할 수 없으며 임의의 기준 위치를 넣지 않는다.
- 조건 전체 결과와 현재 지도 안의 수를 구분한다. '이 지역에서 찾기'는 당시 지도 범위를 목록에 적용하며, 이후 지도 이동은 목록·검색·확대를 자동 초기화하지 않는다.
- 카드에 결제 유형·출처별 확인일·실제 유가와 자료 날짜를 표시한다. 지류/디지털 미확인과 KB국민카드 근거의 적용 범위를 보존한다. LPG에 일반 유가를, 누락 가격에 0원을 표시하지 않는다.
- 모바일 결과는 접기/절반/전체로 전환한다. 목록에서 선택한 상세를 닫으면 선택 행과 목록 스크롤로 돌아온다. 키보드 Escape와 포커스 복귀를 지원한다.
- 상세는 '여기로 길찾기'에서 지도 앱을 고르고, 경유 선택은 보조 행동으로 둔다. 추가 근거는 '확인 정보'에서 펼친다.
- 경유의 추천 조건은 기본 요약으로 접고, 불투명도는 창 설정으로 이동한다. 구 경계 안내는 작은 배지로 줄인다.

검증:
- 로컬 Node 84개 / Python 104개 통과, 사이트 빌드·diff 검사 통과.
- 새 검사는 실제 위치/미허용 정렬, 지도 범위 스냅샷·지도 이동의 분리, 선택 행·스크롤 복귀, SDK 실패 목록, 유종별 유가·미확인 값 보존을 실행한다.
- 기준 커밋 b6c1af3와 비교해 STATIONS / PRICES / PRICE_INFO / MERCHANT_STATUS / NATIONAL_PENDING 내장 데이터 동일 확인.
- 로컬 브라우저는 지도 SDK가 로드되지 않아 주소 목록 대체 흐름을 점검했다. 작은 화면에서 절반/전체·내부 스크롤·빈 결과 복구·다크 테마를 확인했고 가로 넘침이 없었다. 실제 CSS 너비는 371px이며 물리 휴대전화 검증이 아니다.
- 공개 사이트의 실제 지도·상세·경유 검증은 배포 후 확인 결과를 별도로 기록한다. 실제 GPS 전송·휴대전화 내비 실행·현장 결제 확인과 구분한다.
