# 경로 표시와 경로 주변 주유소 추천

## 작업 계약과 라우팅
- 입력: 현재 위치 또는 사용자가 선택한 출발지·목적지, 기존 검증 가맹점/가격, 추천 기준.
- 목적/가설: 운전자가 경로를 보면서 작은 우회로 들를 가맹점을 고를 수 있다. 번호가 같은 지도 핀/목록, 실제 도로 기반 거리·우회시간과 외부 내비 경유 연결로 검증.
- 행동: 도로 경로 조회 → geometry 표시 → 실제 경로와의 거리로 후보 선택 → 24곳씩 도로 행렬 비교 → 기준에 해당하는 모든 추천 표시.
- 수락: 양 끝점 선택 후 경로/번호 목록, 5분 미만의 엄격 경계, Nkm 이내 포함 경계, 빈 결과/실패 복구, 변경 취소, 모바일·키보드·야간 지도, 기존 검증 경계 유지.
- always: canonical identity_harness AGENTS/Skill Router/Brain. active: Project Execution, codex-delivery-loop, KRDS typography, Source/Eval의 Global/UX Gate. reference: 기존 경유 코드·공식 OSRM/Kakao/MapLibre API. excluded: 신규 제품 기획·문체·수집·멀티에이전트·MCP 신설(기존 UI 기능 확장에 불필요).
- 발견: local AGENTS/Project 별도 파일 없음. 이 계약이 사용자 요청의 최소 Project. 인덱스의 예전 workspace_root는 발견용이며 실제 canonical 경로를 사용.

## 구현/경계
- 양 끝점이 선택되면 조회. 목적지만 검색할 때 GPS를 요청하지 않으며 출발지가 비면 사용자가 경유 찾기를 누를 때 위치 요청. 위치 거부 시 수동 출발지 입력 유지.
- 기본 추가 5분 미만, 선택 10/15분 미만. 시간 기준은 경로 10km 이내 가맹점을 조사하는 제한을 결과에 표시. 거리 기준은 1/2/5/10km 이내(경로 선분과의 가장 짧은 지리적 거리, 도로 진입거리와 구분).
- 도로·연료 업종/위치/가맹점 검증 규칙 유지. 과거 미확인 온누리를 추천하지 않음. 후보를 24곳으로 잘라 버리지 않고 전체를 순차 배치.
- OSRM 경로/시간: 실시간 교통, 주유·대기시간, 주유소 진입 방향 미반영. 연결 도로로의 과도한 스냅은 제외. 5분 미만은 300초를 포함하지 않고 초 단위로 표시.
- Kakao Polyline + Overlay와 MapLibre GeoJSON line/point 렌더러가 같은 메모리 상태를 사용. 다크/회전 스타일 재로드 시 경로 복원. 지우기/초기화/입력 수정 시 오래된 선·요청 제거. 개인 출발지·목적지·경로는 URL/localStorage/배포 파일에 기록하지 않음. 요청 시 OSRM으로 좌표 전송(기존 경로 계산 안내 유지).
- UI: 기존 접힌 경유 패널 안에 추천 기준/한도 2개 선택. 본문 16px/1.5/400, 제목 18px/1.5/700, 입력·동작 16px/44px, 지도 핀은 메타 14px. 지도를 넓게 보는 동작은 패널을 접음.

## 출처/검증
- https://project-osrm.org/docs/v5.24.0/api/ (route geometry/duration/distance, table matrix)
- https://apis.map.kakao.com/web/documentation/#Polyline
- https://maplibre.org/maplibre-gl-js/docs/examples/add-a-geojson-line/
- 공개 예시 좌표 광주→목포 route 응답 HTTP 200/Ok, 733개 선분 좌표 확인. 개인 GPS 사용 없음.
- 단위: Node 47/Python 100 통과. 굽은 경로/직선 오판 방지, 24곳 초과 보존, 299.9/300초, 반경 경계, 잘못된 geometry/도로 스냅, 지우기, 테마 교체 복원, 양 끝점 자동 조회/빈 결과 검증.
- 브라우저 검수: 공개 장소 광주송정역→목포역 입력으로 약 58분/68.3km 도로선, 시간 기준 후보 72곳 중 7곳, 반경 2km 기준 6곳을 실제 응답으로 확인. 개인 GPS 사용 없음. Kakao 기본 지도와 MapLibre 야간/밝은 스타일의 선·출발/도착·번호 핀 및 내비 링크 확인. 모바일 결과 뒤 조건 접기로 목록을 확보. 후속 좁은 폭·지우기·최종 화면 증거 검수 중. 실제 휴대폰 위치 권한/멀티터치/내비 앱 진입은 별도 기기 검증 범위.
