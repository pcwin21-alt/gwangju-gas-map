# 공개 웹 v2 배포 — 2026-11-06

요청: 현재 로컬 시안을 실제 서비스에 배포. 대상은 공개 웹 `https://pcwin21-alt.github.io/gwangju-gas-map/`이며 앱인토스 업로드·심사·출시 교체는 이번 작업에서 수행하지 않는다.

## 변경과 데이터 경계

GasBuddy 중심으로 검토한 v2의 검색·필터 시트·가격 핀·비교 목록·상세·주황 팔레트·한국어 고정을 공개 웹에 연결했다. 현재 원격 main의 지도 HTML을 바탕으로 승격하므로 고정된 11월3일 검토 자료로 되돌리지 않는다. `STATIONS/PRICES/PRICE_INFO/MERCHANT_STATUS/NATIONAL_PENDING` 5개 내장 자료는 승격 전후 원문이 같다. 가격 JSON·가맹점 JSON·확인일·수집기·대기열·정책 내용은 변경하지 않았다. 최신 원격 기준은 작업 시작 시 `d2a63e3`이다.

공개 경로 서버는 미연결이다. 공개 웹에서는 실제 사용할 수 없는 경로 계산·출발지·경유 입력을 숨기고, 상세의 **길찾기 → 카카오맵/네이버지도 선택 또는 주소 복사**를 제공한다. REST 비밀키·로컬 서버·모의 응답을 공개 빌드에 넣지 않는다. 토스 SDK 없이도 웹 위치 권한과 지도앱 연결 경로가 작동하도록 분기했다. 실제 휴대전화의 외부 앱 실행·복귀 성공은 아직 검증하지 않았다.

시안에서 제외했던 후원·제보 전송·반응 서비스 코드를 되살리지 않고, 관련 공개 자격정보와 자동 방문 도움말도 제거했다. 문의 메일 링크는 유지하며 자동 발송하지 않는다. 테마는 기존 더보기의 기기 설정/밝게/어둡게를 유지한다. 영어 모듈은 로드하지 않는다.

출시 자산은 `assets/fuel-ui/`에 폰트·라이선스와 함께 둔다. `scripts/promote_web_v2.py`는 현재 데이터 보존·중복 승격 방지를 검사한다. `scripts/prepare_site.py`가 하위 폴더 CSS/JS에도 파일 해시를 붙여 배포 후 캐시를 구분한다. 다음 가격 자동 갱신은 기존 내장 가격 상수만 갱신하므로 v2 화면을 보존한다.

## 검수

- Python203개·Node116개 통과. 새 승격 검사는 신규 날짜/가격/미확인 후보를 포함한 자료를 보존하며 반복 적용되고, 언어·개발 서버·제외된 전송 코드가 나오지 않는지 확인한다. 기존 지도 확대·입력·지역 전환·가격·정책 검사도 통과했다.
- 새 화면 스크립트3개의 구문 검사 통과. 실제 가격·가맹 수집은 실행하지 않았다.
