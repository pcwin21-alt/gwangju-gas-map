# 전남 무검색어 조사 — 2026-10-26

## 실행 계약

전남부터 실제 연료 영업장 좌표 주변을 상호 조건 없이 조회하고, 기존 후보 명부의 누락을 지자체 명부로 보완한다. 확인된 신규 지점을 공개 지도에 반영한다. 전남→광주→전북→경남→경북→부산→대구→울산→충남→충북→대전→세종→강원→제주→경기→인천→서울 순서 유지. 각 지역 전체 조사 완료와 확인된 지점 우선 발행을 구별한다.

가설: 상호가 `법인명 (지점명)`으로 등록된 주유소는 `주유` 키워드 검색에서 누락된다. 완료 기준: 새로운 조회 경로의 실측 결과, 동일 영업장 검증, 잘못된 이웃 점포 매칭 방지 검사, 공개 반영 확인. 전체 반환 소매점 수를 주유소 수로 보고하지 않는다.

라우팅: canonical identity_harness AGENTS/START/Brain/Router·Project Execution·Source·Global Eval 적용. 이전 추가 발견 경로 검토는 reference. UI 재설계, 기관 연락, 차단 우회, 계정 정보, 메모리 변경 제외. 인덱스의 옛 workspace_root는 drift로 기록하고 실제 canonical 경로 적용.
