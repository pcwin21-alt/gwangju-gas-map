# 상세창 중립색·가운데 정렬 — 2026-11-02

사용자 첨부 화면을 기준으로, 상단 파란 띠 디자인을 없애고 적절한 가운데 정렬로 가독성을 높이도록 요청받았다.

- 파란 상단 강조선·파란 외곽선·제목 배경을 제거한다. ~~파란 띠~~ → **얇은 중립색 경계와 그림자**로 창을 구분한다. 지도 음영과 클릭 통과는 유지한다.
- 주유소명·주소·결제 유형·확인일·가격 기준일·거리 안내는 가운데 정렬한다. 유종과 가격은 **좌우 정렬**을 유지해 수치를 비교하기 쉽게 한다.
- 이름은 카드 전체 폭의 중심에 맞춘다. 닫기 버튼 공간은 좌우 대칭으로 확보하고, 380px 이하에서는 제목을 닫기 버튼 다음 행으로 내려 큰 글자도 좁은 열에 끼지 않도록 한다.
- 닫기 버튼은 회색 바탕으로 구분하고 기존 sticky 위치·44px 터치 영역·키보드 동작을 유지한다.
- 라이트/다크 중립색 토큰을 사용한다. 결제 확인 상태·가격·위치·기능·이용 흐름은 바꾸지 않는다.
- 적용 계약: 기존 Toss UX/KRDS/codex-delivery-loop의 가독성·맥락 보존·실제 렌더 검사만 이번 카드 수정 범위에 적용한다. 신규 기능/가맹점 수집/브랜드 변경은 제외한다.

검증 기준: 320/390/PC, 200% 글자, 라이트/다크에서 긴 제목·주소와 가격 넘침이 없고, 닫기/길찾기/경유 버튼이 사용 가능하다. 제목 중심과 카드 중심이 일치하고 상단에 별도 색 띠가 없어야 한다. 실제 검증과 배포 결과는 아래에 추가한다.

## 로컬 검증

- 실제 브라우저 렌더 10조합: 320×740 / 390×844 / 1280×800 기본 글자 및 320·390 너비의 200% 글자, 각각 라이트/다크. 카드와 내부 요소 가로 넘침 0건.
- 모든 조합에서 제목이 카드의 가용 콘텐츠 폭 중심에 일치했다. 스크롤바가 생기는 경우 그 폭을 제외해 측정했다. 상단 테두리 1px, 제목 배경 투명도 확인했다.
- 닫기 버튼은 기본 44px, 200% 글자에서 88px. 390px 대표 화면에서 중립색 카드·가운데 정렬을 스크린샷으로 확인했다. 로컬 예시 가격은 검수용 합성 값이다.
- 관련 Node 테스트 15개 통과: 상세창, 핀 반복 선택/터치, 가격, 테마. `python scripts/prepare_site.py`와 `git diff --check` 통과.

## 후속 조정: 정보별 색상 변주

사용자가 중립색 구성을 유지하면서 비슷한 톤 사이에 변주를 요청했다. **결제 정보 확인 → 가격 비교 → 이동/경유 선택** 과업에서 정보와 행동을 구분하도록 다음처럼 좁게 수정한다.

- 결제 유형: ~~회색 바탕~~ → **옅은 세이지색 바탕·진한 녹색 글자**. 문구와 확인일은 유지하며, 색을 신규 검증 상태로 사용하지 않는다.
- 유종·가격 행: ~~옅은 회색~~ → **따뜻한 아이보리색**. 유종은 짙은 갈색, 금액은 기존 진한 글자로 유지한다.
- 경유 버튼: ~~투명 바탕의 텍스트~~ → **청록색 채움 버튼**. 외부 지도 버튼과 구분하고 hover 상태도 제공한다.
- 창 본체·닫기 버튼·외부 지도 버튼의 중립색과 가운데 정렬은 유지한다. 파란 상단 띠는 복원하지 않는다. 다크모드에는 각 역할의 별도 토큰을 적용한다.

작업 계약/라우팅: 기존 화면을 입력으로 CSS 색상만 변경한다. 완료 조건은 라이트·다크 대비 4.5:1 이상, 320/390/PC·200% 글자에서 가로 넘침 없음, 기능·데이터·초점 동작 보존, 실제 배포 확인이다. root/Brain/최소 Project 계약은 always, `toss-ux-principles`와 `codex-delivery-loop`는 active(전문 읽기·현재 도구로 구현/렌더 검증), 기존 기록은 reference다. 신규 사이트 기획·글쓰기·이미지 생성·가맹점 수집·서브에이전트는 이 CSS 수정 범위 밖이므로 excluded다. 인벤토리 파일과 선택한 로컬 스킬의 존재를 확인했다. 하네스 색인 최상위 workspace 경로는 이전 위치지만, 이번 실행은 명시된 canonical root의 실제 파일을 사용한다. 사용자 요청은 기존 화면의 색상 수정이며 경쟁사 스타일 복제나 의미 없는 장식 추가는 하지 않는다.
