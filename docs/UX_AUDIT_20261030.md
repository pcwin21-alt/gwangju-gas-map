# 지도 전면 사용성 점검

계약: 기존 단일 카카오 지도와 가맹점 근거는 유지하면서 검색/지역/필터/목록/상세/경유/보조 메뉴/테마/좁은 화면의 실제 이용 흐름을 점검한다. 재현하거나 코드와 검사로 확정한 오류를 수정하고 공개 배포 및 브라우저 검증으로 확인한다. 제보·댓글 제출, 결제, 실제 위치 전송은 점검에 필요하지 않아 수행하지 않는다. 실제 휴대전화와 내비 앱 실행은 미검증으로 구분한다.

진행 계획: 1. 현재 화면 재현 및 코드 대조 → 2. 영향이 큰 오류 수정과 회귀 검사 → 3. 320/390px·가로 화면·데스크톱·테마 및 실제 경로 흐름 확인 → 4. 배포/원본 동기화와 남은 제약 보고.

범위 구분: 경유 주유소를 직접 지정한 흐름은 외부 지도 연결이며, 해당 지점의 추가시간은 계산하지 않았다고 표시한다. 일반 추천 흐름은 실제 OSRM 도로/행렬 결과로 계산한다. 실제 사용자의 GPS·내비 앱·제보·댓글 제출·후원 결제는 실행하지 않았다. 잠시 넣은 조건부 진단 로그는 최종 카드 수정에서 제거했다.

상세창 추가 원인: 기존 `.info-overlay`의 absolute 위치와 `translate(-50%, calc(-100% - 14px))`가 SDK의 yAnchor와 겹쳤다. 고정 카드로 전환하면서 이 위치·변환을 명시적으로 초기화했다. 320×740에서 카드 (12,161)~(308,598), 닫기 44×44px로 화면 안에 유지되고 다음 도구 호출 후에도 DOM이 남는 것을 확인했다.

브라우저 점검 결과:

- 320×740 상세 읽기/명시적 닫기/닫은 뒤 결과 보기로 포커스 복귀, 자동으로 사라지지 않음, 경유 선택 시 상세 닫힘.
- 없는 상호 검색→0곳→목록의 검색어 지우기→130곳으로 복구. 도움말·가격 순위 Escape 닫기 및 더보기 버튼으로 포커스 복귀. 가격 순위 Enter 진입.
- 주유소(돌고개)를 먼저 지정→광주역 목적지 선택→광주청사 출발지 검색·선택 후 돌고개 경유 결과 유지. GPS 조회 없이 공개 장소를 수동 선택했다.
- 일반 추천: 광주청사→광주역 약 10분·6.1km, 실제 도로/행렬로 112곳 비교·29곳 추천. 지도 기본 후보 5개, 전체 목록 29개. 29번 컨벤션주유소의 지도에서 보기로 실제 상세 카드 진입 확인.
- 844×390 밝은 테마의 경유창이 화면 안에 들어오고 본문 스크롤 가능, 가로 넘침 없음. 지도 전체 화면 390px 높이 및 복귀, 1280×900에서도 넘침 없음. 테마는 기존 기기 설정으로 복구했다.
- 자동 검사 최종 Node 74개/Python 100개, 빌드 및 diff 검사 통과. 최종 기능 커밋 `6f40f02`, 검사 41004888829/41004888508, 배포 41004888836 및 Pages 41004902073 성공.
- 최종 버전 LPG 조건: 16곳 비교·3곳 추천 실제 확인. 경로가 표시된 상태에서 전남을 선택하자 일반 지도 28곳, routeMode=false, 경로 핀 0개로 복귀했고 목적지 광주역 입력은 유지됐다. route 증빙은 Playground/output/onnuri-ux-route-20261030.jpg. 마지막에는 광주/온누리 기본 페이지로 복귀하고 임시 화면 크기를 해제했다.
- 관측된 브라우저 오류 로그 없음. 진단 중간 커밋의 테스트 실패(브라우저 location을 제공하지 않은 테스트 환경)는 진단 코드 제거 후 최종 전체 검사 통과로 해소했다.
- 증빙: Playground/output/onnuri-ux-detail-20261030.jpg. 최종 점검은 공개 사이트에 버전 쿼리를 붙여 오래된 HTML 캐시와 구분했다. 실기기 터치/핀치, 내비 앱 실행, 실제 GPS 허용/차단, 폼 제출·결제는 미실행이며 해당 경로의 단위 검사와 실기기 검증을 구분한다. 브라우저 200% 확대는 실행하지 않았다.
