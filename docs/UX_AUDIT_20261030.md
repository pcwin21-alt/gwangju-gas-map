# 지도 전면 사용성 점검

계약: 기존 단일 카카오 지도와 가맹점 근거는 유지하면서 검색/지역/필터/목록/상세/경유/보조 메뉴/테마/좁은 화면의 실제 이용 흐름을 점검한다. 재현하거나 코드와 검사로 확정한 오류를 수정하고 공개 배포 및 브라우저 검증으로 확인한다. 제보·댓글 제출, 결제, 실제 위치 전송은 점검에 필요하지 않아 수행하지 않는다. 실제 휴대전화와 내비 앱 실행은 미검증으로 구분한다.

진행 계획: 1. 현재 화면 재현 및 코드 대조 → 2. 영향이 큰 오류 수정과 회귀 검사 → 3. 320/390px·가로 화면·데스크톱·테마 및 실제 경로 흐름 확인 → 4. 배포/원본 동기화와 남은 제약 보고.

확인된 항목:

| 항목 | 근거 | 조치 |
| --- | --- | --- |
| 주유소 상세에 닫기 없음, 지도 버튼이 내용 가림 | 320×740 공개 화면 재현 | 명시적 닫기·Escape·내용 겹침 방지 |
| 검색 예약 fit이 사용자의 새 지도 조작 뒤 실행 가능 | 350ms 검색 타이머와 지도 입력 경로 대조 | 직접 조작 시 예약 이동 취소 |
| 지도 클릭 닫기 이벤트가 주유소마다 중복 등록 | STATIONS 루프 내부 등록 | 지도에 한 번만 등록 |
| 출발지/목적지 비동기 검색이 공용 결과 목록을 뒤늦게 덮어씀 | 종류별 버전만 비교 | 전체 검색 순서도 비교 |
| GPS 대기 중 출발지를 수정해도 과거 GPS가 입력을 덮어씀 | tripLocation 경로에 세대 확인 없음 | 세대 검증과 중복 요청 방지 |
| 일부 보조 패널에 Escape·포커스 복귀/순환 없음 | 기존 class 기반 패널 핸들러 | 공통 접근성/닫기 처리 |
| 목적지 전에 고른 경유 주유소를 다시 선택해야 함 | chooseStation의 조기 반환 | 선택을 기억하고 출발/목적지 입력 뒤 연결 |
| 결과 0곳에서 복구 행동이 안내 문장에만 있음 | 목록 렌더 분기 | 검색어 지우기·필터 초기화·지역 바꾸기 제공 |
| 한글 조합 중 검색 예약 이동 가능 | input 처리에 조합 구분 없음 | 조합 완료 후 검색 적용 |
| 지역 변경 후 과거 구 음영이 남을 수 있음 | districts는 값만 초기화 | 구 음영도 함께 해제 |
