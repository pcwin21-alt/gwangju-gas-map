# 온누리 가맹점 주소 목록 우선 조사

## 질문과 수락 조건

기존 격자 조회를 반복하지 않고 온누리 가맹 주유소를 찾을 다른 작동 경로를 검증한다. 전남 우선. 입력은 KB 공개 조회 화면의 실제 주소 검색 필드와 기존 조사 기록이다. 다른 좌표에서도 같은 행정구역 가맹점 ID 목록이 반환되고, 표시 총수와 회수 수가 일치하면 주소 목록 경로가 작동한다고 판정한다. 가맹점 신규 추가·전남 전수조사 완료와 구별한다.

라우팅: canonical AGENTS/Brain/Router always, Research Synthesis/Source/Global Eval active, 기존 프로젝트 조사 reference. UI 변경·기관 연락·계정정보·메모리 쓰기·하위 에이전트 excluded. 인덱스 옛 workspace_root는 drift. 새로운 별도 서비스용 Skill은 활성화하지 않았다.

## 실제 확인

KB 공개 화면에는 `주소로 찾기`가 있고 시도·시군구·읍면동을 받는다. 반경 방식의 `locationType=1`과 별개로 주소 방식 `locationType=2`가 동작한다. 온누리 조건 `useCase=1`, 상호 조건은 공란으로 유지했다.

| 조건 | 전체 업종 가맹점 수 | 반환 고유 ID 수 |
|---|---:|---:|
| 담양읍 내 좌표, 반경 방식 | 36 | 36 |
| 같은 좌표, 담양읍 주소 방식 | 460 | 460 |
| 약 80km 떨어진 좌표, 같은 담양읍 주소 방식 | 460 | 460 |

주소 방식 두 응답의 가맹점 ID 집합은 완전히 일치한다. 460은 주유소 수가 아니다. 주유소 분류는 백동산업·대나무·터미널·부원 네 행이다. 백동은 이전에 기록한 업종 충돌이 해결되지 않았다. 터미널은 지도에 이미 있으므로 신규 추가로 집계하지 않는다.

터미널주유소의 KB 상호·전화(061-383-4460)와 오피넷 A0020014의 상호·전화가 일치한다. 오피넷 주소는 담양읍 죽향문화로 98이다. 두 좌표는 약 1,727m 차이가 난다. 따라서 실제 영업장 좌표 주변만 조회하는 기존 방식에는 가맹점이 있어도 검색되지 않는 구체적 실패 사례가 있다. 주소 목록은 이 좌표 오류에 의한 누락을 줄일 수 있다. 다른 주소·사업자 충돌까지 해결한다고 주장하지 않는다.

시도나 시군구만 넣고 읍면동을 비우는 두 시험은 0행이었다. 이를 지역 전체 미가맹으로 해석하면 안 된다. **서버가 제공하는 모든 읍면동 값을 명시적으로 열거해야 한다.** 지역 목록 응답의 `area`를 읽어야 하며 기본 강원 데이터가 든 `areaSgguList`를 잘못 사용하면 안 된다. 이번에 전남 22개 시군과 담양군 13개 읍면동 표기를 확인했다. 남면/가사문학면처럼 옛 이름과 새 이름이 함께 있어 최종 가맹점 ID 중복 제거가 필요하다.

## 적용 순서

1. KB 주소 선택 목록에서 전남 22개 시군의 모든 읍면동 값을 확보한다.
2. 각 주소의 온누리 가맹점을 상호 조건 없이 조회한다. 응답 총수·고유 ID·주소 일치·기준일을 보존한다. 총수와 회수 수가 다르거나 요청 실패면 미완료로 남긴다.
3. 가맹점 ID로 중복을 제거한 후 주유소·차량용 충전소 분류와 명칭 후보를 추린다. 기타소매업 등으로 분류된 가맹점도 연료 영업장 명부와 상호·주소로 역대조한다.
4. 오피넷/인허가의 상호·전화·상세주소로 동일 영업장을 검증한다. KB 좌표를 지도 좌표로 그대로 쓰지 않는다. 충돌은 별도 보류한다.
5. 기존 온누리 운영사·연간 명부와 대조해 지류/카드/QR 범위를 구분한다. KB 조회만으로 모든 결제수단을 확정하지 않는다. 확인된 목록과 미확인 목록을 나눈다.

공공데이터포털의 2026-07-31 전국 가맹점 명부는 이미 이전 조사에서 전체 비교한 자료다. 이를 새 발견 경로로 다시 소개하지 않는다. 상세주소가 없고 취급품목이 공란일 수 있으며 연간 갱신이어서 현재 전체 명부의 대체물은 아니다. 최신 전체 명부가 필요하면 소진공에 시군별 상호·상세주소·업종·가맹 상태·결제유형·기준일을 요청하는 방안이 별도로 남는다. 외부 요청은 제출하지 않았다.

검증 상태: 담양읍 주소 조회 실험 통과. 전남 모든 읍면동 수집은 아직 실행하지 않았다. 이번 실험의 신규 지도 추가 0. 지도·가격·기존 확인일 변경 없음.
