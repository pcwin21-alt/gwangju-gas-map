사용자가 지정한 문구 ~~이 지역에서 찾기~~ → **보고 있는 화면에서 조회하기**를 그대로 적용했다. ~~지도에 항상 남던 ‘주유소 전체/찾은 범위 N곳’ 접힌 바~~ → **조회 버튼 한 개**로 통합했다. 버튼은 왼쪽 상단에서 바로 사용할 수 있고, 누르면 클릭 시점의 지도 범위를 캡처해 결과 목록을 연다. 열린 목록 안에는 ‘조회 결과 N곳’과 닫기 ×만 표시하며, 닫기·Escape 후에는 결과 바가 사라지고 조회 버튼으로 초점이 돌아온다.
