# 경유 검색 플로팅 창

- 요청/목적: 상단 고정 경유 메뉴를 없애 지도와 검색 결과를 원활히 오가기. 지도 터치 시 원형 버튼으로 최소화, 버튼으로 복원, 배경 투명도 선택.
- 계약: 기존 입력/결과/경로 상태를 보존하면서 지도 영역 안의 비모달 창으로 이동. 새 주소/경로 계산이나 지도 재생성 없이 열기/최소화. 지도 pan/pinch 이벤트 취소 금지, 입력 필드 터치는 창 유지, 키보드 Escape/최소화도 복원 가능한 버튼으로 연결.
- 최소 조합: 이전 canonical Skill Router/Brain/Project Execution/Source/Eval Global·UX, codex-delivery-loop/KRDS/computer-use 유지. 기존 UI 후속 구현이므로 신규 제품 기획/데이터 조사/문체/MCP/멀티에이전트 제외. 본 문서가 Project 계약과 상태 기록.
- HTML tripPanel을 map-area 안으로 옮김. 별도 원형 경유 버튼, 추천 수 badge, 비모달 dialog semantics. 열린 창은 지도 상단 오른쪽 최대 440px/지도 높이 72%, 내부 스크롤. 닫힌 상태는 원형 버튼만 남김. 기본 검색 바와 지도 크기는 창 열고 닫기에 따라 바뀌지 않음(키보드 열린 모바일은 입력 공간 확보).
- 배경 불투명도 100/90/75%. 패널 배경 RGBA만 변경하고 텍스트·버튼은 opaque 유지. 선택값만 localStorage 저장. 경로·위치·입력값을 저장하지 않음. themechange 시 밝은/어두운 팔레트 다시 적용.
- 일반 지도 pointer/touch는 창을 최소화하면서 원래 제스처를 통과. 팝업 자체와 경유 원은 제외. 입력 요소를 비동기로 focus하지 않음. 다시 열면 헤더 버튼에 focus, 사용자가 입력칸을 누르면 native 편집 시작. 추천의 지도 보기와 지도 크게 보기도 최소화 연결.
- 글자/입력/동작은 기존 16px/1.5, 최소 44px. badge/배경 라벨은 메타 14px. popup 결과는 좁은 너비에 맞춰 한 열로 배치.
- 단위: Node 53개 통과. 입력·결과 보존, 제스처 취소 없음, popup 내 터치, touch fallback, Escape 복원, 배경만 투명도, 원형 버튼 결과 수 확인. 기존 경로/키보드/검증 경계 검사 포함.
- 브라우저: 배포 후 검수 예정. 실물 Android/카카오톡·네이버 WebView 키보드 검증은 이 PC에서 불가하며, DOM focus/축소 화면 및 계산을 별도로 검증.
