# 이용 흐름 및 주유소 상세창 구분 — 2026-11-02

## 요청·범위·수락 조건

사용자는 버튼 클릭/기능 사용 순서를 고려한 UI/UX 수정과, 상세창이 열렸음을 과하지 않게 시각적으로 구분하는 수정을 요청했다.

- 첫 흐름: 내 주변 → 명시적인 위치 확인 → 현재 검색 조건의 가까운 순 목록 → 상세 → 길찾기/경유.
- 두 번째 흐름: 가는 길 → 목적지 입력/선택 → 출발지/조건 확인 → 경유 후보 → 상세/내비 연결.
- 상세창: 이름/주소 다음 결제 유형 → 유가 → 이동 정보 → 행동 순서. 테두리·그림자·제목 강조와 옅은 지도 음영으로 비모달 창을 구분한다.
- 기존 원칙: 첫 방문 자동 GPS/자동 키보드 없음. 지도 팬/줌·검색·필터·경유 입력을 관계없는 버튼으로 초기화하지 않는다. 위치 응답이 늦게 도착해 다른 화면/지도를 덮어쓰지 않는다.
- 범위 밖: 가맹점 수집/검증·할인율/가격 계산·새 결제수단·정밀 위치/경로 서버 저장. 이번 수정에서는 조건 기억 기능도 추가하지 않는다.
- 산출물: 기존 HTML/CSS/스크립트 개선, 작은 검색 흐름 모듈, 행동 회귀 시험, 로컬 검수 화면 및 본 기록.

## 구현

1. 검색 조건/건수 행에 '내 주변'과 '가는 길'을 배치했다. 지도 공간을 크게 차지하는 안내 화면은 추가하지 않는다.
2. 내 주변은 버튼을 누를 때만 위치를 요청한다. 성공하면 가까운 순 목록을 열고, 실패하면 검색/지역 선택 안내를 표시한다. 검색어·지역·결제 조건은 유지한다. 목록 범위와 정렬 기준을 명확히 표시한다.
3. 가는 길은 목록/필터/상세를 정리하고 기존 경유 창을 연다. 입력은 보존하고 처음 포커스는 제목 summary에 둔다. 플로팅 원은 경유 창을 한 번 연 뒤 최소화했을 때 표시한다.
   공개 지도에서 필터와 경유 창이 함께 열리는 상황도 확인했다. 필터·지역 버튼 또는 검색 입력으로 지도 검색을 시작하면 경유 창을 접고 입력을 유지하도록 정리했다.
4. 위치를 기다리는 동안 중복 요청을 막고, 경로 전환·검색 입력·필터 변경·지도 직접 조작이 있으면 늦은 위치 응답의 자동 이동/목록 열기를 무시한다. 실제 위치 콜백이 전역 위치·마커·정렬 갱신 이벤트를 발생시키기 전에도 취소 여부를 검사한다.
5. 상세/목록/경유 카드에서 결제·유가·이동 정보의 순서를 맞췄다. 경유 카드 결제 문구도 기존 공통 증거 표시 함수를 사용해 KB 등 발급사 제한을 유지한다. LPG/액체 연료 가격을 구분한다.
6. 상세창에 푸른 회색 경계, 얇은 상단 강조선, 그림자, 옅은 제목 배경, 분명한 닫기 버튼을 적용했다. 지도 음영은 클릭을 가로채지 않는다. 다크 모드도 별도 토큰을 사용한다. 색 외에 경계·그림자·포커스와 dialog 의미를 함께 제공한다.

## 검증 계약

- 자동: 자동 GPS 없음, 중복 방지, 정상 위치 결과→목록, 거부→수동 검색, 늦은 응답이 경로/지도 조작을 방해하지 않음, SDK 실패 fallback, 필터 보존, 경유 입력 보존, 핀 클릭 안정성.
- UI: 320/390px, 짧은 가로 화면, 200% 글자, 라이트/다크, 한영 전환. 상세창/닫기/하단 행동 가독성과 가로 넘침을 확인한다.
- 로컬 검수 생성기는 실제 화면/크기/번역/흐름 모듈을 사용하되 지도와 위치는 명시적인 검수용 대체 함수다. 실제 GPS·도로 서비스 호출 없이 정상/거부 상태를 확인한다. 실제 기기 검증과 구분한다.
- 공개 배포 후 목적 버튼→경유 창, 검색→목록→상세→복귀, 다크/라이트 상세창과 버전 반영을 확인한다. 실제 GPS 권한은 대신 허용하지 않는다.
