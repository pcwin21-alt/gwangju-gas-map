# 유류 품목까지 확대한 전국 온누리 가맹점 대조

## 작업 계약과 적용 범위

목표: 주유소 이름이 없는 법인·유류 품목 등록을 전체 공식 파일에서 발굴하고, 실제 차량 주유 업종과 정확한 장소가 확인된 누락 지점을 지도에 반영한다. 온누리 이용자는 지도에서 확인 근거와 결제수단 범위를 보고 방문 여부를 판단한다.

입력 → 행동 → 수락 증거 → 출력: 2026-07-31 공식 225,803행 및 원본 해시 → 품목·상호 검색, 등록 주유소 역대조, 전국 상권자료 전체 업종 대조, 해당 사업장 좌표에서 KB 공개 조회 → 가맹 표시·주유 업종·상호·상세주소·좌표 일치 및 기존 지점 불변 비교 → 새 지점, 제외 근거, 날짜가 붙은 조사 결과와 공개 지도.

가설: 법인명과 비표준 품목 등록으로 검색에서 빠진 실제 주유소가 있다. 반증/실패 조건: 같은 이름 또는 가까운 좌표만 일치하거나, 가정용 연료 판매업·정비업 등과 업종이 충돌하면 지도 추가를 허용하지 않는다.

## 조사 범위와 결과

- 공식 온누리 전체 225,803행: 상호뿐 아니라 유류, 석유, 휘발유, 경유, 등유, 무연, 차량용 연료, LPG 등 품목 검색. 우유류·섬유류 같은 부분 문자열 오탐 제외.
- 공공 주유소·LPG 위치자료 7,329행, 상권자료의 주유소·충전소 14,360행을 역대조.
- 전체 후보 278행, 상호·상점가·지역 기준 276묶음. 후보 수는 실제 주유소 수가 아니다. 같은 이름의 음식점·수산물점과 품목 오기도 포함된다.
- 전국 상권정보 16개 지역 파일, 전체 업종 2,772,484행 재대조. 전남/광주 파일부터 서울 마지막 순서. 상호만 같은 다른 사업장과 가정용 연료점을 구분했다.
- KB 사업장 위치 기반 조회 29개 질의(양성 대조 질의 포함), 응답 수·페이지·가맹점 ID 중복 검사. 앞선 무관한 위치의 탐색 질의 17개는 지역 조사 근거에서 제외했다. 검색이 반경 영향을 받으므로 지역 밖의 빈 결과를 비가맹 증거로 사용하지 않는다.

신규 지도 반영: **(주)동행**, 광주 광산구 북문대로 364-5. 공식 파일의 ㈜동행/주유소/신창동가구의거리일번국도상점가 등록을 출발점으로, 상권자료의 동행/주유소/신창동 1083-8과 KB 공개 조회의 (주)동행/주유소/온누리 표시를 대조했다. 두 독립 좌표 간 4.9m, 은행 소재지 신창동과 상권자료 지번 일치. KB 가맹점 000000084182837, 상권업소 MA010120220809878430. 확인 시각 2026-10-30T18:34:39+09:00.

지도는 온누리 **184곳 = 액체연료 167 + LPG 17**. 기존 219개 저장 지점을 변경하거나 삭제하지 않고 1곳 추가했다. 전체 지도 좌표 보유 217곳(상생카드 포함), 저장 220행이다. KB 표시 지류·QR·다른 카드사 이용 가능 여부는 확정하지 않았다.

새 제외 근거 3곳: 거제제일가스, 영남가스 주식회사, 광주석유판매협동조합. 운영사 검색의 상호·상점가·주소와 상권자료 주소가 정확히 같고 상권 업종은 가정용 연료 소매업이다. 현장 좌표에서 KB 조회도 가스판매점 또는 연탄 및 유류판매점으로 확인됐다. 차량 주유소 후보에서만 제외하며 온누리 가맹 자체를 부정하지 않는다. 기존 대기 목록은 동행 추가와 광주석유판매협동조합 제외로 12 → 10곳이다. 이 10곳은 종전 목록 범위이며 새 조사 전체의 미확정 수가 아니다.

청우에너지 등 나머지 미확정 등록은 날짜와 원천을 보존해 대기한다. 단일 법인명이 여러 장소에 있거나 현재 결제수단·사업장 연결이 부족한 곳을 추정해서 추가하지 않았다. 용전주유마트는 KB의 차량 정비/부품 업종으로 확인했으며 같은 주소의 기존 용전주유소와 별도 신규 주유소로 세지 않았다. 대창가스는 상권자료의 가스 충전소 표기와 KB 가스판매점 분류가 충돌해 추가하지 않았다.

## 수집기 보완

scripts/official_onnuri.py의 후보 선택을 품목 중심으로 확대했다. 선택 버전을 올려 옛 선택 기준의 캐시 재사용을 막았다. 공공데이터포털이 contentUrl 대신 fn_fileDataDown 및 selectFileDataDownload 절차를 제공하는 형식도 지원한다. 실제 페이지의 인자와 응답의 첨부파일 ID만 사용하며 임의 파일 ID를 만들지 않는다. 이상 응답은 실패 처리하고 기존 데이터를 보존한다.

원본을 10월 30일 새로 다운로드했지만 해시는 기존 파일과 같고 기준일도 7월 31일이다. 재조회일을 원천 기준일로 바꾸지 않았다. 공식 실시간 검색 API는 HTTP 400 Request Blocked 상태이며 우회하지 않았다. 따라서 전국 전수성·오늘 전체 가맹 수·실제 결제 성공은 확인 범위 밖이다.
