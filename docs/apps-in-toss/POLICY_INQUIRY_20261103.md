## 보낼 내용

안녕하세요. `온누리 주유소 지도`(appName: `onnuri-fuel-map`)의 앱 등록을 준비하고 있습니다.

이 서비스는 확보한 주유소의 주소, 온누리·지역화폐 가맹 확인 범위와 확인일, 자료 기준일의 유가를 지도·목록으로 보여주는 정보 조회 서비스입니다. 현재 위치는 사용자가 버튼을 누르고 허용할 때만 조회하며, 거절해도 지역·주소로 검색할 수 있습니다.

차량 매매·할부·리스·렌트·정비 예약, 결제, 상품권 판매·충전·환전, 광고, 중개 수수료 기능은 없습니다. 콘솔에서 선택한 카테고리는 `자동차 → 주유·충전`입니다.

공개 서비스 오픈 정책의 자동차 관련 서비스 한시 제한과 실제 콘솔의 주유·충전 분류를 함께 확인했습니다. 위 범위의 정보 조회 서비스로 검토 요청이 가능한지, 추가로 필요한 서류나 고지가 있는지 확인 부탁드립니다. 다른 분류로 변경해 제한을 피하려는 의도는 없습니다.

감사합니다.

## 판단 근거와 경계

- 공개 정책: https://developers-apps-in-toss.toss.im/intro/guide.md 의 `3. 출시 불가 서비스·콘텐츠` 중 `9) 한시적 출시 불가 카테고리`.
- 실제 콘솔: 자동차/주유·충전 선택과 자동차 판매·예약금 관련 확인란을 관찰했다.
- 선택 가능하다는 사실만으로 최종 입점 예외를 확정하지 않는다. 지원팀에 보낼 메시지는 사용자에게 문안을 제시하고 발송 지시를 받은 뒤 전송한다.
- 문의에는 연락처, 계정 식별 정보, API 키, 테스트 QR/배포 식별자, 위치 좌표를 포함하지 않는다.
