## 콘솔에서 진행할 순서

1. [기존 앱 빌드 화면](https://apps-in-toss.toss.im/workspace/105239/mini-app/onnuri-fuel-map/app-build)에 로그인한다. 계정·약관·책임 동의는 해당 내용을 확인한 사용자가 수행한다.
2. 앱 정보에서 현재 로고와 설명을 확인한다. 미등록이면 `logo-600.png`를 올리고 아래 문구로 기존 임시저장 내용을 대조한다. 이미 등록된 appName은 바꾸지 않는다.
3. 앱 번들 화면에 같은 폴더의 `onnuri-fuel-map.ait`를 업로드한다. 업로드 성공과 발급된 테스트 QR/스킴을 확인한다. 로컬 빌드 로그의 deploymentId를 업로드 성공으로 간주하지 않는다.
4. 지도 제공자 콘솔의 허용 도메인을 확인한다. SDK 3.9.0 기준 후보는 `https://onnuri-fuel-map.apps.tossmini.com`과 `https://onnuri-fuel-map.private-apps.tossmini.com`이다. 실제 QR 실행 Origin과 일치해야 한다. 도메인 설정을 수행하거나 확인한 상태는 아니다.
5. 콘솔의 **토스앱 테스트** QR을 만 19세 이상·로그인된 워크스페이스 멤버의 토스 앱으로 연다. 아래 필수 테스트를 실행하고 기기/OS/토스 버전/업로드 버전/결과를 기록한다. [공식 가이드](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace.md)는 최소 1회 테스트 완료를 검토 요청 조건으로 명시한다.
6. 소개한 기능, 문의 수신 주소, 권한·실제 데이터 흐름과 필요한 고지를 대조한다. 정책·자격·책임 확인 문구를 사실대로 검토한다.
7. 모두 확인된 버전으로 **검토 요청하기**를 누른다. 이 문서 작성 시점에는 요청하지 않았다. 결과는 콘솔·이메일에서 확인하고 반려 사유별로 수정한다. 공식 안내는 영업일 3~7일이며 개별 일정 보장은 아니다.
8. 승인 후 버전 내역의 **출시하기**가 별도 단계다. 승인 상태와 공개 출시 상태를 혼동하지 않는다.

업로드가 다시 확장 프로그램의 파일 접근 제한으로 실패하면 보안 설정을 임의로 바꾸지 않고 위 두 파일을 사용자가 직접 업로드한다. 이전 실패를 현재 성공으로 표시하지 않는다.

## 심사자에게 전달할 기능 범위·재현 설명

별도 회원가입과 로그인 없이 첫 화면에서 광주 지역 주유소 정보를 확인할 수 있습니다. 지역 선택과 결제수단 필터로 범위를 바꿀 수 있고 검색창에서 상호 또는 주소를 검색할 수 있습니다. 지도 마커를 누르면 확보한 주소·결제 확인 범위·확인일과 유가 기준일을 확인할 수 있습니다. 지도 제공자가 실패하면 주소 목록과 수동 검색을 유지합니다.

위치 조회는 사용자가 내 위치 버튼을 눌렀을 때 SDK 권한을 확인해 1회 호출합니다. 거절 시 수동 조회를 유지합니다. 테스트 후보는 로그인·상품권 판매/충전/환전·주유비 결제·광고·외부 후원·시범 경로 계산을 제공하지 않습니다. 공개 웹의 경유 추천과 외부 길찾기는 이 후보의 소개 기능에 포함하지 않습니다.

온누리·지역화폐 발행사나 운영사의 공식 앱이 아니며, 수집 범위와 확인일에 한계가 있는 독립 정보 서비스입니다. 과거 가맹 근거와 카드사별 재확인을 구분하고 전국 전수 수집·실시간 가격·현재 결제 가능을 보장하지 않습니다.

## 정책·데이터 흐름 확인 과제

**최종 적합성:** 11월 3일 [서비스 오픈 정책](https://developers-apps-in-toss.toss.im/intro/guide.md) 3-9에는 자동차 관련 서비스의 한시적 제한이 있다. 이 정보 지도의 최종 적합성은 미확정이다. 앱 생성 사전 확인을 최종 승인으로 표현하지 않는다. 심사에 위 기능 설명을 제공하고 판단을 받는다. 개별 앱의 사전 승인 답변을 받았다고 주장하지 않는다.

**소스에서 확인한 흐름:** 지도 SDK는 카카오에 요청된다. 내 위치는 토스 SDK에서 받아 지도 표시·직선거리 계산에 사용한다. 익명 식별키와 언어 설정은 로컬 저장소에 저장한다. 가맹점/가격은 번들에 포함되며 현재 위치를 가맹점 수집 서버에 보내는 기능은 이 후보에 포함하지 않는다. 기존 제보·반응·분석·후원 코드와 시범 경로 스크립트는 실행 대상에서 제외했다.

**남은 확인:** 지도 SDK가 받는 지도 영역·검색·접속 정보, 제3자 보관·이전·약관 조건과 우리 고지 범위는 실제 네트워크 및 제공자 문서로 확인해야 한다. HTML의 출처 링크 목록은 실제 네트워크 수신자 목록과 다르다. 번들 소스만 보고 ‘개인정보 수집 없음’으로 확정하지 않는다. 외부 출처 링크의 실제 토스 내 동작도 확인한다. 필요한 개인정보/위치 관련 문서는 이 조사 메모를 완성된 법적 고지로 사용하지 않는다.
